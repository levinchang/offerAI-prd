# Offer信息站 - 管理后台页面原型

基于 PRD（M1～M7）与 **UI/UX PRO MAX** 设计系统生成的静态页面原型，采用 HTML + Tailwind CSS + 原生 JS，无后端依赖。

## 设计系统摘要

- **风格**：Data-Dense Dashboard，数据表与筛选为主，留白适中
- **主色**：Primary `#7C3AED`，背景 `#FAF5FF`，文案 `#4C1D95`
- **字体**：Fira Sans（正文）、Fira Code（标题/系统名）
- **图标**：Lucide Icons（SVG），无 emoji
- **交互**：可点击元素 `cursor-pointer`，hover 过渡 200ms，焦点态可见

## 文件说明

| 文件 | 说明 |
|------|------|
| `login.html` | 管理员登录页（居中卡片、账号/密码/记住账号、前端校验） |
| `index.html` | 主后台框架：左侧菜单 220px + 顶栏 + 主内容区，多页切换 + 编辑抽屉 |

## 使用方式

1. 用浏览器直接打开 `login.html`，输入任意账号密码后点击「登录」会跳转到 `index.html`
2. 打开 `index.html` 后，左侧菜单切换：飞书同步（配置/任务）、校招岗位、事业编岗位、面试资料、订单列表、会员列表、用户列表、反馈列表、**系统设置**（管理员管理、字典管理）
3. 列表页中的「编辑」「新增岗位」「新增资料」「查看详情」等会打开右侧抽屉或弹窗（原型无真实提交）

## 与 PRD 对应关系

- **M1.1** 管理员登录 → `login.html`（默认 Admin / admin1234 见 M1.2）
- **M2.1** 飞书同步配置 → 配置页 + 编辑抽屉（含 App ID/Secret/Token）+ 测试连接弹窗 + 手动同步弹窗
- **M2.2** 飞书同步任务 → 任务页（筛选、表格、手动同步、**查看详情**、重试）
- **M2.4** 飞书同步任务详情 → 行内「查看详情」打开**任务详情抽屉**（任务ID、数据类型、触发方式、状态、时间、同步结果、失败原因）
- **M3.1** 校招岗位列表 → 列表页（上架状态、批量上架/下架、多示例：飞书/人工、已上架/未上架）
- **M3.2** 校招岗位编辑 → 右侧抽屉（上架状态只读、底部「仅保存」「保存并上架」）
- **M4.1 / M4.2** 事业编列表与编辑 → 列表页 + 编辑抽屉（上架状态、仅保存/保存并上架；类型含事业单位、国企、公务员、遴选、大学生村官、银行、教师编、其他）
- **M5.1** 面试资料管理 → 列表页 + 新增/编辑抽屉
- **M6.1** 订单管理 → 订单列表 + 筛选；行内「查看详情」打开**订单详情抽屉**（订单号、用户、商品、金额、支付渠道、状态、支付流水）
- **M6.2** 会员管理 → 会员列表（已购资料列、延长校招/延长事业编弹窗）
- **M7.1** 用户列表 → 用户列表（手机号、邮箱、账号状态、禁用/启用）+ 筛选
- **M7.2** 反馈处理 → 反馈列表 + 筛选
- **M1.2** 管理员管理 → 系统设置 → 管理员列表 + **新增管理员**按钮 + **编辑**打开**管理员新增/编辑抽屉**
- **M8.1** 校招表字典 → 系统设置 → 字典管理 → **校招表字典** Tab：**字段列表**（字段名、字段键名、字段类型=枚举、必填），点击「招聘类型」「所属行业」行进入**字段详情**抽屉，编辑字段属性 + **枚举值列表**（显示名、编码、排序、状态、新增枚举值）
- **M8.2** 事业编岗位字典 → 同上结构，**事业编岗位字典** Tab 下字段列表为「类型」（枚举），点击进入详情编辑类型枚举值（事业单位、国企、公务员、遴选、大学生村官、银行等）。后续可扩展：**新增字段**（必填/非必填、类型、枚举时填枚举值、数值时填范围等）

## 技术栈

- Tailwind CSS（CDN）
- Google Fonts：Fira Sans、Fira Code
- Lucide Icons（UMD）
- 原生 JavaScript（页面切换、抽屉开关、登录跳转）
