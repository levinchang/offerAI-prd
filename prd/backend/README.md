# 后台管理 PRD 索引

## UI 规范（统一）

- **整体布局**：典型中后台风格，**左侧固定菜单 + 右侧主内容区**；所有业务页面均遵循此结构（登录页除外，登录页为居中卡片，无左侧菜单）。
- **左侧菜单**：
  - 固定宽度（建议 220px），垂直导航；
  - 一级菜单：飞书同步、校招岗位、事业编岗位、面试资料、会员与订单、用户与反馈、**系统设置**；
  - 子级：飞书同步下「配置」「任务」；会员与订单下「订单列表」「会员列表」；用户与反馈下「用户列表」「反馈列表」；**系统设置**下「管理员管理」「字典管理（招聘类型/所属行业）」。
- **右侧主内容区**：
  - 列表页：上方「筛选区」+ 中部「表格」+ 底部分页；左上/右上为「新增」「导出」等主操作。
  - 编辑/新增页：多块「表单卡片」+ 底部固定「取消」「仅保存」「保存并上架」（岗位类）；或「取消」「保存」；或使用右侧抽屉/滑出表单。**上架状态**统一为「已上架/未上架」，通过底部按钮或列表「上架」操作，不在表单项内下拉选择。
  - 详情：只读信息 + 操作按钮（如延长会员、处理反馈、禁用/启用用户）。
- **顶栏**：LOGO、系统名称「Offer信息站-管理后台」、当前管理员账号、退出登录。
- **表格**：支持排序、勾选（批量操作）、行内操作（编辑、删除、上架、下架等）。
- **表单**：按信息块分卡片，必填项用 * 标注；校验失败时在字段旁或顶部展示错误提示。
