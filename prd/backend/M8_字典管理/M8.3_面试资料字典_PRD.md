# M8.3 面试资料字典（资料行业、资料岗位）

| 项目 | 说明 |
|------|------|
| **功能名称** | 面试资料字典：资料行业、资料岗位的枚举维护 |
| **对应 FeatureList** | 面试资料中「行业」「岗位」筛选项与后台编辑的数据来源 |
| **对应 ER 实体** | 字典字段表、字典枚举值表（与 M8.1 共用，通过 field_key 区分） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- **面试资料字典**与校招表字典分离，专门服务于**面试资料**模块：前台「资料商城」的行业/岗位筛选、后台「面试资料管理」编辑页的行业下拉与岗位多选，均从本字典拉取枚举值。
- 目标：管理员在「字典管理 → 面试资料字典」中维护**资料行业**（doc_industry）、**资料岗位**（doc_position）的枚举内容；数据结构与 M8.1 一致（字段 + 枚举值），便于复用同一套字典表与接口。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「系统设置」→「字典管理」→ **「面试资料字典」**；右侧主内容区为**字段列表**（仅两条：资料行业、资料岗位）；点击行进入**字段详情**（抽屉或独立页），在详情内编辑该字段的枚举值列表。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

### 3.1 字段列表（主列表）

- **列表列**：字段名（资料行业、资料岗位）、字段键名（doc_industry、doc_position）、字段类型（枚举）、操作（**查看/编辑**）。
- **交互**：点击行或「查看/编辑」→ 打开该字段的**详情页/抽屉**，在详情内编辑**枚举值内容**。
- **预置**：面试资料字典预置两条字段——**资料行业**（field_key = doc_industry）、**资料岗位**（field_key = doc_position），类型均为枚举。

### 3.2 字段详情（点击列表进入）

- **区块一 - 字段属性**：字段名、字段键名、字段类型（枚举，只读）。
- **区块二 - 枚举值列表**：  
  - 表格列：显示名、编码、排序值、状态（启用/禁用）、操作（编辑、禁用/启用、删除）。  
  - 操作：「**新增枚举值**」；行内「编辑」打开枚举项编辑（弹窗或行内编辑）。  
  - 保存后关闭详情或刷新枚举列表。

### 3.3 与 M8.1 的差异

- 面试资料字典**不提供「新增字段」**，仅维护上述两个预置字段的枚举值。
- 若未来需要扩展更多资料相关字段，可再在本文档或 M8.1 中约定。

---

## 4. 字段规格表

### 4.1 预置字段

| 字段显示名 | 字段键名 | 类型 | 说明 |
|------------|----------|------|------|
| 资料行业 | doc_industry | 枚举 | 前台资料商城「行业」筛选、后台资料编辑「行业」下拉 |
| 资料岗位 | doc_position | 枚举 | 前台资料商城「岗位」筛选、后台资料编辑「岗位」多选 |

### 4.2 枚举值（在详情内维护）

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 说明 |
|------------|----------|------|------|------|------|
| 显示名 | label | 枚举列表/表单 | string | 是 | 如 互联网、银行、产品经理 |
| 编码 | code | 枚举列表/表单 | string | 否 | 存储值，不填则用显示名 |
| 排序值 | sort_order | 枚举列表/表单 | int | 否 | ≥0，默认 0 |
| 状态 | status | 枚举列表/表单 | enum | — | 启用/禁用 |

---

## 5. 业务逻辑与联动

- **R-01**：前台「资料商城」行业/岗位筛选项来自 `GET /api/dict/doc_industry`、`GET /api/dict/doc_position`，仅返回 status=启用的项，按 sort_order 排序（与 03_接口与鉴权 一致）。
- **R-02**：后台「面试资料管理」编辑页：行业为单选用 doc_industry 枚举；岗位为多选，用 doc_position 枚举；保存时 `docs.industry` 存 code 或 label，`docs.job_type` 存多选值（JSON 或逗号分隔），见 M5.1、02_数据模型与存储。
- **R-03**：删除或禁用枚举项时，若已被某条面试资料引用，建议禁止删除或仅逻辑禁用，并在界面提示。

---

## 6. 异常与边界

- 同一字段下枚举项显示名/编码不可重复。
- 无枚举值时，详情内枚举列表为空状态「暂无枚举值，请新增」。

---

## 7. 依赖与待定项

- **依赖**：字典字段表、字典枚举值表（与 M8.1 共用）；面试资料表 docs 的 industry、job_type 字段；M5.1 面试资料管理、F5 资料商城。
- **与 M8.1 的关系**：校招表字典负责 recruit_type、industry 等；面试资料字典仅负责 doc_industry、doc_position，二者在后台菜单上并列展示，底层可共用同一套 dict_fields / dict_items 表与接口（通过 field_key 区分）。
