# M8.1 校招表字典（字段列表 + 枚举内容编辑）

| 项目 | 说明 |
|------|------|
| **功能名称** | 校招表字典：字段列表维护，点击进入详情编辑字段配置与枚举值 |
| **对应 FeatureList** | 校招岗位中招聘类型、所属行业等字段的数据来源 |
| **对应 ER 实体** | 字典字段表、字典枚举值表（或等价结构） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- **校招表字典**以「字段」为管理单元：先展示**字段列表**（如 招聘类型、所属行业），每个字段有**类型**（如 枚举）；点击某字段进入**详情**，在详情内编辑该字段的**枚举内容**（枚举值列表的增删改）及字段属性。
- 目标：管理员在「字典管理 → 校招表字典」看到字段列表，点击「招聘类型」「所属行业」等进入详情，编辑枚举值；后续可扩展为支持**手动新增扩展字段**（必填/非必填、类型、枚举值或数值范围等）。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「系统设置」→「字典管理」→ **「校招表字典」**；右侧主内容区为**字段列表**；点击列表行进入**字段详情**（抽屉或独立页），在详情内编辑枚举内容等。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

### 3.1 字段列表（主列表）

- **列表列**：字段名（如 招聘类型、所属行业）、字段键名、**字段类型**（枚举 / 数值 / 文本 等）、是否必填、操作（**查看/编辑**）。
- **交互**：点击行或「查看/编辑」→ 打开该字段的**详情页/抽屉**，在详情内编辑字段属性与**枚举值内容**（当类型=枚举时）。
- **预置**：校招表字典预置两条字段——**招聘类型**（类型：枚举）、**所属行业**（类型：枚举）。

### 3.2 字段详情（点击列表进入）

- **区块一 - 字段属性**：字段名、字段键名、是否必填、**字段类型**（枚举 / 数值 / 文本 等，可读或可改视实现）。  
  - 当**类型=枚举**时，展示**区块二**。  
  - 当**类型=数值**时，可填写**取值范围**（最小值、最大值等，见 4.2）。  
  - 当**类型=文本**等时，可按类型展示对应配置（长度、格式等）。
- **区块二 - 枚举值列表**（仅当字段类型=枚举时）：  
  - 表格列：显示名、编码、排序值、状态（启用/禁用）、操作（编辑、禁用/启用、删除）。  
  - 操作：「**新增枚举值**」；行内「编辑」打开枚举项编辑（弹窗或行内编辑）。  
  - 保存后关闭详情或刷新枚举列表。

### 3.3 扩展：新增字段（后续）

- 列表上方「**新增字段**」：可手动添加扩展字段。  
- 表单：字段名、字段键名、**是否必填**（必填/非必填）、**字段类型**（枚举 / 数值 / 文本 等）。  
  - **类型=枚举**：需在保存后或同页配置**枚举值**（可在此步填写枚举值列表，或保存后在详情中编辑枚举内容）。  
  - **类型=数值**：可填写**范围**（如最小值、最大值、单位）。  
  - **类型=文本**：可填写最大长度、格式等。  
- 扩展字段用于校招岗位表或表单的扩展配置，具体落表与展示规则由实现与产品后续约定。

---

## 4. 字段规格表

### 4.1 字段列表与字段属性

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 说明 |
|------------|----------|------|------|------|------|
| 字段名 | field_name | 列表/详情 | string | 是 | 如 招聘类型、所属行业 |
| 字段键名 | field_key | 列表/详情 | string | 是 | 如 recruit_type、industry，存储与接口用 |
| 字段类型 | field_type | 列表/详情 | enum | 是 | 枚举 / 数值 / 文本 等 |
| 是否必填 | required | 列表/详情 | bool | — | 该字段在岗位表单中是否必填 |

### 4.2 枚举值（当字段类型=枚举时，在详情内维护）

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 说明 |
|------------|----------|------|------|------|------|
| 显示名 | label | 枚举列表/表单 | string | 是 | 如 26届春招、金融业 |
| 编码 | code | 枚举列表/表单 | string | 否 | 存储值，不填则用显示名 |
| 排序值 | sort_order | 枚举列表/表单 | int | 否 | ≥0，默认 0 |
| 状态 | status | 枚举列表/表单 | enum | — | 启用/禁用 |

### 4.3 数值型字段配置（当字段类型=数值时，后续扩展）

| 字段显示名 | 字段键名 | 区域 | 类型 | 说明 |
|------------|----------|------|------|------|
| 最小值 | min_value | 详情 | number | 可选 |
| 最大值 | max_value | 详情 | number | 可选 |
| 单位 | unit | 详情 | string | 可选，如 年、个 |

- **招聘类型** 预置枚举值：26届春招、26届秋招、暑期实习、日常实习等。  
- **所属行业** 预置枚举值：金融业、IT互联网游戏AI、房地产建筑业等。

---

## 5. 业务逻辑与状态流转

- **R-01**：岗位编辑页、筛选区的「招聘类型」「所属行业」下拉选项来自对应字段的枚举值列表接口，仅返回状态=启用的项，按 sort_order 排序。
- **R-02**：飞书同步时若枚举值在系统中不存在，可调用「枚举新增」接口自动新增该字段下的枚举项，详见 M2.3。
- **R-03**：删除枚举项时若已被岗位引用，建议禁止删除或仅逻辑禁用。
- **R-04**：扩展字段（新增字段）的必填/类型/枚举值或范围仅影响该字段在表单中的校验与展示，落库与 ER 由实现约定。

---

## 6. 异常与边界

- 同一字段下枚举项显示名/编码不可重复。
- 无枚举值时，详情内枚举列表为空状态「暂无枚举值，请新增」。

---

## 7. 依赖与待定项

- **依赖**：字典字段表、字典枚举值表（或等价）；校招岗位表引用字段键名及枚举 code/label；**面试资料模块（M5.1）引用资料行业/岗位相关字典字段**。
- **已定（与面试资料联动）**：在「字典管理」中新增字段：
  - **资料行业**：`field_key = doc_industry`，类型=枚举；其枚举值作为前台「面试资料 → 行业」筛选项，以及后台面试资料编辑页的行业下拉来源。
  - **资料岗位**：`field_key = doc_position`，类型=枚举；其枚举值作为前台「面试资料 → 岗位」筛选项，以及后台面试资料编辑页的岗位多选来源。
- **待定**：企业类型（国企/民企等）是否作为校招表字典中的单独字段维护；扩展字段与岗位表/表单的绑定方式（配置化或预置字段）；资料行业/岗位是否单独拆出为 M5 资料分类子模块还是完全复用本字典管理。
