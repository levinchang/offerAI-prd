# M8.2 事业编/国企岗位类型枚举维护

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编岗位「类型」枚举维护（与校招字典分开） |
| **对应 FeatureList** | 事业编岗位列表与编辑中「类型」字段数据来源 |
| **对应 ER 实体** | 字典表（dict_type = civil_unit_type 或等价） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 事业编/国企岗位的「类型」字段（单位类型）需在后台单独维护，与**校招表字典**（招聘类型、所属行业）区分开，便于扩展与筛选。
- 目标：管理员在「字典管理 → 事业编岗位字典」中维护**岗位类型**（如事业单位、国企、公务员、遴选、大学生村官、银行等）；列表可增删改查，支持排序/启用禁用；事业编岗位编辑页与筛选区从接口拉取选项。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「系统设置」→「字典管理」→ Tab 或子菜单**「事业编岗位字典」**（与「校招表字典」并列）；右侧为类型列表 + 新增/编辑。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

- **布局**：字典管理下分 **校招表字典** / **事业编岗位字典** 两个子区；事业编岗位字典下为「类型」列表。
- **类型列表**：列：序号、编码/键、显示名、排序值、状态（启用/禁用）、操作（**编辑**、禁用/启用、删除）。
- **操作区**：「**新增类型**」按钮；行内「**编辑**」打开编辑抽屉/弹窗。
- **新增/编辑**：抽屉或弹窗，字段：显示名（必填，如「事业单位」「国企」「公务员」「遴选」「大学生村官」「银行」）、编码（可选）、排序值（数字，默认 0）、状态（启用/禁用）；底部「取消」「保存」；保存后刷新列表。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 长度/格式 | 说明 |
|------------|----------|------|------|------|-----------|------|
| 枚举类型 | dict_type | — | 固定 | — | civil_unit_type | 事业编岗位类型 |
| 编码/键 | code | 列表/表单 | string | 否 | ≤50 | 存储值，岗位表 unit_type 存此值 |
| 显示名 | label | 列表/表单 | string | 是 | ≤100 | 如 事业单位、国企、公务员、遴选、大学生村官、银行 |
| 排序值 | sort_order | 列表/表单 | int | 否 | ≥0 | 升序，默认 0 |
| 状态 | status | 列表/表单 | enum | — | 启用/禁用 | 禁用后不在岗位编辑下拉中展示 |

- **初始预置**：事业单位、国企、公务员、遴选、大学生村官、银行、教师编、其他等（与 M4 事业编岗位「类型」一致，可扩展）。

---

## 5. 业务逻辑与状态流转

- **R-01**：事业编岗位编辑页、列表筛选的「类型」下拉选项来自本模块接口，仅返回状态=启用的项，按 sort_order 排序。
- **R-02**：删除时若已被岗位引用，建议禁止删除或仅逻辑禁用。
- **R-03**：与 M8.1 校招表字典（招聘类型、所属行业）**分开维护**，入口与列表独立，便于区分校招与事业编两类业务。

---

## 6. 依赖与待定项

- **依赖**：字典表/枚举表；事业编岗位表 unit_type 引用其 code 或 label。
- **待定**：是否与 M8.1 共用同一张字典表（通过 dict_type 区分）由实现决定。
