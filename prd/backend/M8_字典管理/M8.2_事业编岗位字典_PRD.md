# M8.2 事业编岗位字典（字段列表 + 枚举内容编辑）

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编岗位字典：字段列表维护，点击进入详情编辑枚举值 |
| **对应 FeatureList** | 事业编岗位「类型」等字段的数据来源 |
| **对应 ER 实体** | 字典字段表、字典枚举值表（与 M8.1 可共用或按业务区分） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 与**校招表字典**同一套设计：**字段列表** + **点击进入详情编辑枚举内容**。事业编岗位字典下预置字段为「**类型**」（单位类型，字段类型=枚举），点击进入详情后编辑该字段的枚举值（事业单位、国企、公务员、遴选、大学生村官、银行等）。
- 目标：管理员在「字典管理 → 事业编岗位字典」看到字段列表（至少「类型」），点击进入详情编辑类型枚举值；后续可扩展新增字段（必填/类型/枚举值或范围等），与 M8.1 扩展能力一致。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「系统设置」→「字典管理」→ **「事业编岗位字典」**；右侧为**字段列表**；点击行进入**字段详情**，编辑字段属性与枚举值。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

### 3.1 字段列表

- **列表列**：字段名、字段键名、**字段类型**（枚举等）、是否必填、操作（查看/编辑）。
- **预置**：**类型**（字段键名如 unit_type，字段类型：枚举）。
- **交互**：点击「类型」行 → 打开详情，在详情内编辑**类型**的枚举值列表（事业单位、国企、公务员、遴选、大学生村官、银行、教师编、其他等）。

### 3.2 字段详情

- 同 M8.1：字段属性（字段名、键名、必填、类型）；当类型=枚举时展示**枚举值列表**，支持新增/编辑/删除枚举项。
- 类型字段的枚举值预置：事业单位、国企、公务员、遴选、大学生村官、银行、教师编、其他。

### 3.3 扩展

- 后续可「新增字段」，必填/非必填、类型（枚举时可填枚举值、数值时可填范围等），与 M8.1 扩展一致。

---

## 4. 字段规格表

- **字段属性**：同 M8.1 的 4.1（字段名、字段键名、字段类型、是否必填）。
- **枚举值**：同 M8.1 的 4.2（显示名、编码、排序值、状态）。
- **类型** 预置枚举值：事业单位、国企、公务员、遴选、大学生村官、银行、教师编、其他。

---

## 5. 业务逻辑与状态流转

- **R-01**：事业编岗位编辑页、列表筛选的「类型」下拉来自本字段的枚举值接口，仅返回启用项，按排序展示。
- **R-02**：删除枚举项时若已被岗位引用，建议禁止删除或仅逻辑禁用。

---

## 6. 依赖与待定项

- **依赖**：字典字段表、字典枚举值表；事业编岗位表 unit_type 引用类型字段的枚举 code/label。
- **待定**：与 M8.1 是否共用同一套表结构（通过业务类型或 scope 区分校招/事业编）。
