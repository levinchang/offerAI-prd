# M8.1 校招表字典维护（招聘类型、所属行业）

| 项目 | 说明 |
|------|------|
| **功能名称** | 校招岗位用：招聘类型、所属行业枚举维护 |
| **对应 FeatureList** | 校招岗位中招聘类型、所属行业的数据来源 |
| **对应 ER 实体** | 字典表/枚举表（dict_type=recruit_type / industry） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- **校招表字典**与**事业编岗位字典**分开维护：本 PRD 仅负责**校招**相关的「招聘类型」「所属行业」；事业编岗位的「类型」见 **M8.2 事业编岗位类型枚举**。
- 校招岗位的「招聘类型」「所属行业」选项需在后台维护，供校招编辑页下拉/多选使用；飞书同步时若枚举值不存在可调用本模块的「新增枚举项」接口自动新增。
- 目标：管理员在「字典管理 → 校招表字典」中维护招聘类型、所属行业；列表可增删改查，支持排序/启用禁用；**提供新增/编辑页面（抽屉或弹窗）**。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「系统设置」→「字典管理」→ Tab 或子菜单**「校招表字典」**（与「事业编岗位字典」并列）；右侧为枚举类型切换（招聘类型 / 所属行业）及列表 + **新增/编辑**。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

- **布局**：左侧菜单 + 右侧主内容区。可选左侧为枚举类型切换（招聘类型 / 所属行业），右侧为当前类型的列表。
- **招聘类型**：
  - 列表列：序号、编码/键、显示名、排序值、状态（启用/禁用）、操作（**编辑**、禁用/启用、删除）。
  - 操作区：「**新增招聘类型**」；行内「**编辑**」打开编辑抽屉/弹窗；删除需二次确认（若已被岗位引用可禁止删除或仅软删除）。
- **所属行业**：
  - 同上结构，列表列：序号、编码/键、显示名、排序值、状态、操作。
  - 操作区：「**新增行业**」；行内「**编辑**」打开编辑抽屉/弹窗。
- **新增/编辑页面**：抽屉或弹窗，字段：显示名（必填）、编码（可选，用于存储值，不填则用显示名）、排序值（数字，默认 0）、状态（启用/禁用）；底部「取消」「保存」；保存后关闭并刷新列表。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 长度/格式 | 说明 |
|------------|----------|------|------|------|-----------|------|
| 枚举类型 | dict_type | — | enum | — | recruit_type / industry / company_type 等 | 区分招聘类型、行业、企业类型等 |
| 编码/键 | code | 列表/表单 | string | 否 | ≤50 | 存储值，岗位表存此值；不填则用显示名 |
| 显示名 | label | 列表/表单 | string | 是 | ≤100 | 前台与后台展示用 |
| 排序值 | sort_order | 列表/表单 | int | 否 | ≥0 | 升序排列，默认 0 |
| 状态 | status | 列表/表单 | enum | — | 启用/禁用 | 禁用后不在岗位编辑下拉中展示，已引用保留展示 |

- **招聘类型** 初始可预置：26届春招、26届秋招、暑期实习、日常实习等。
- **所属行业** 初始可预置：金融业、IT互联网游戏AI、房地产建筑业等（与 FeatureList 3.2.3 一致）。

---

## 5. 业务逻辑与状态流转

- **R-01**：岗位编辑页、筛选区的招聘类型/所属行业下拉选项来自本模块接口，仅返回状态=启用的项，按 sort_order 排序。
- **R-02**：飞书同步时若枚举值在系统中不存在，可调用「枚举新增」接口（传入 dict_type + label/code）自动新增，详见 M2.3。
- **R-03**：删除时若该枚举值已被岗位引用，建议禁止删除或仅做逻辑禁用，避免历史数据缺展示。

---

## 6. 异常与边界

- 重复显示名/编码：同一 dict_type 下显示名或编码不可重复。
- 无数据：列表空状态「暂无枚举项，请新增」。

---

## 7. 依赖与待定项

- **依赖**：字典表/枚举表；校招/事业编岗位表引用其 code 或 label。
- **待定**：企业类型（国企/民企等）是否也纳入校招表字典统一维护。**事业编「类型」**由 **M8.2 事业编岗位类型枚举** 单独维护，不在本 PRD。
