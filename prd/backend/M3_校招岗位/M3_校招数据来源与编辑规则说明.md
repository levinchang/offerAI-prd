# 校招岗位：数据来源与编辑规则说明

本文档对校招岗位的**数据来源**、**新增/编辑字段与校验**、**可编辑性**、**上架/下架逻辑**做集中说明，便于与 M3.1/M3.2 及开发对齐。

---

## 1. 数据来源

| 来源 | 说明 | 唯一标识 | 来源标签 |
|------|------|----------|----------|
| **人工新增** | 列表「新增岗位」进入，所有字段人工填写 | source_key 系统生成（如 UUID） | 人工增加 |
| **飞书同步** | M2 按配置从飞书多维表格拉取，按 field_mapping 写入 | 企业名称 + 招聘岗位 → source_key | 飞书同步 |

---

## 2. 新增页：字段与校验

| 字段 | 必填 | 校验规则 | 数据来源 |
|------|------|----------|----------|
| 企业名称 | 是 | 非空，去首尾空格，≤100 | 人工输入 |
| 企业类型 | 是 | 枚举其一（字典或固定） | 人工选择 |
| 招聘类型 | 是 | 至少选一，来自 M8.1 招聘类型 | 人工多选 |
| 工作地点 | 否 | 省→市→区级联，支持搜索多选 | 人工选择 |
| 招聘岗位 | 是 | 非空，≤200 | 人工输入 |
| 所属行业 | 否 | 若填须在 M8.1 所属行业枚举内 | 人工多选 |
| 网申开始/截止日期 | 否 | 开始 ≤ 截止 | 人工输入 |
| 毕业生要求 | 否 | ≤500 字 | 人工输入 |
| 信息来源 | 否 | ≤200 | 人工输入 |
| 投递链接 | 是 | 非空，URL 格式，≤500，存储加密 | 人工输入 |
| 原文链接 | 否 | URL 格式，≤500，存储加密 | 人工输入 |

- 新增时**上架状态**固定为「未上架」；仅通过「保存并上架」或列表「上架」变为已上架。

---

## 3. 修改：哪些字段允许编辑？

| 允许编辑 | 只读/不可改 |
|----------|---------------------|
| 企业名称、企业类型、招聘类型、工作地点、招聘岗位、所属行业、网申日期、毕业生要求、信息来源、投递链接、原文链接、手动锁定 | 来源标签、source_key（若有展示）；**上架状态**不在表单项内编辑，通过底部按钮或列表操作 |

- 上架状态变更方式：**仅保存**（不改变当前状态）、**保存并上架**（设为已上架）、列表行内**上架/下架**。

---

## 4. 上架/下架逻辑

```mermaid
flowchart LR
  A[未上架] -->|保存并上架 / 列表「上架」| B[已上架]
  B -->|列表「下架」/ 编辑页下架| A
```

- **已上架**：前台可见、可解锁；publish_status = ON_SHELF。
- **下架**：publish_status = OFF_SHELF；若需防止飞书同步再次改为上架，需同时设置**手动锁定=true**（下架时建议提示勾选）。
- **飞书同步**：来源=飞书同步且未开手动锁定的记录，同步可覆盖字段；若被下架且未开手动锁定，飞书同步可再次将其改为已上架。开启手动锁定后，飞书不同步覆盖、不恢复上架。

---

## 5. 与 M3.1 / M3.2 的对应

- 列表筛选、批量上架/下架/删除：M3.1。
- 编辑表单、仅保存/保存并上架、工作地点级联、枚举来自字典：M3.2。
- 本说明为 M3 的集中细化，与 M3.1/M3.2 一致。
