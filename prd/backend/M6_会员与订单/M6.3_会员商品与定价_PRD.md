# M6.3 会员商品与定价

| 项目 | 说明 |
|------|------|
| **功能名称** | 会员商品（SKU）配置与定价管理 |
| **对应 FeatureList** | 9.6.3 会员商品配置 |
| **对应 ER 实体** | 会员商品（SKU）、订单 |
| **对应时序图** | 复用 M6.1 订单与支付时序图（商品维度） |

---

## 1. 需求背景与目标

- 前台套餐选择页与收银台需要从后台配置的「会员商品（SKU）」中获取价格与有效期，支持校招会员、事业编会员、双会员等不同组合，避免价格硬编码在前端。
- 目标（V1）：在后台提供简单的会员商品列表，支持新增/编辑/上下架 SKU，配置名称、类型（校招/事业编/全站）、有效期天数、原价与促销价，标记是否在前台展示；前台套餐页仅展示「已上架且标记展示」的 SKU，价格与有效期全部以此为准。
- 规划（V2）：支持更复杂的定价策略（按月订阅、自动续费、渠道价等），但不在本期实现。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：后台左侧「会员与订单」分组 → 「会员商品与定价」菜单（见后台原型）；右侧为筛选 + 表格；后续可扩展新增/编辑弹窗。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

- **布局**：左侧菜单 + 右侧主内容区。
- **列表筛选区**（Should，可简化）：按商品类型（校招/事业编/全站）、状态（上架/下架）、是否展示过滤。
- **表格列**：SKU ID、名称、类型（校招/事业编/全站）、有效期天数、原价、促销价、是否在前台展示、状态（上架/下架）、更新时间、操作（编辑、上下架）。
- **新增/编辑 SKU**（可抽屉/弹窗）：
  - 字段：SKU ID（只读或自动生成）、名称、类型（校招/事业编/全站）、有效期天数（如 365）、原价、促销价（可选）、是否在前台展示（开关）、状态（上架/下架）。
  - 交互：保存时校验必填与金额格式；上架前必须配置有效期与原价；促销价可选且需 ≤ 原价。
  - 规则：SKU 可以下架但不删除；已下架 SKU 前台不再展示且不可用于新订单（历史订单不受影响）。
- **与前台的关系**：
  - 前台套餐选择页（F2.2）通过接口获取「会员商品」列表，只展示 `status=上架` 且 `show_in_front=true` 的 SKU（如校招 19.9/年、事业编 19.9/年、双会员 29.9/年）。
  - 收银台（F7.1）根据用户选择的 `sku_id` 展示商品名称与价格，并创建对应商品的订单。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 说明 |
|------------|----------|------|------|------|------|
| SKU ID | sku_id | 列表/详情 | string | 是 | 唯一标识，如 `SKU_CAMPUS_YEAR` |
| 商品名称 | name | 列表/表单 | string | 是 | 如「校招会员-1年」「双会员-1年」 |
| 商品类型 | type | 列表/表单 | enum | 是 | campus / civil / all |
| 有效期天数 | duration_days | 列表/表单 | int | 是 | 如 365 |
| 原价 | list_price | 列表/表单 | decimal | 是 | 单位元 |
| 促销价 | promo_price | 列表/表单 | decimal | 否 | 可为空；若不为空则 ≤ 原价 |
| 是否在前台展示 | show_in_front | 列表/表单 | boolean | 是 | 控制是否在套餐页展示 |
| 状态 | status | 列表/表单 | enum | 是 | 上架/下架 |
| 更新时间 | updated_at | 列表 | datetime | — | 最近修改时间 |

---

## 5. 业务逻辑与状态流转

- **R-01**：前台只能使用 `status=上架` 的 SKU 创建订单；下架后仅影响新订单，历史订单与已有权益不变。
- **R-02**：前台套餐页仅展示 `show_in_front=true` 的 SKU；可以通过配置实现「只卖双会员」或「只卖单卡」等策略。
- **R-03**：优惠码与活动价格在订单侧（F7.1/M6.1）处理，SKU 表仅维护基础价与促销价；前台展示「划线价 + 实付价」时以订单返回金额为准。
- **R-04（V1）**：不支持自动续费 SKU；会员到期续费通过用户再次选择 SKU 下单完成。后续若支持自动续费，将在 V2 中增加订阅型 SKU 类型与签约字段。

---

## 6. 异常与边界

- 删除：V1 不支持物理删除 SKU，仅支持下架；如需彻底下线某 SKU，可通过数据运维处理。
- 金额为 0：不建议配置 0 元会员 SKU，如有需要应在活动/优惠码侧处理，避免与正常付费 SKU 混淆。

---

## 7. 依赖与待定项

- **依赖**：SKU 配置表、订单表；前台套餐选择页与收银台接口；会员权益计算逻辑（根据 SKU 类型与有效期天数决定到期时间）。
- **待定（V2）**：是否支持订阅型 SKU（自动续费）、渠道价、按月/按季等更多计费周期；是否在后台提供 SKU 版本管理或变更历史。
