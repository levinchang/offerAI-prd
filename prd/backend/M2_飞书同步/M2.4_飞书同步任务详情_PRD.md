# M2.4 飞书同步任务详情

| 项目 | 说明 |
|------|------|
| **功能名称** | 飞书同步任务详情页/抽屉 |
| **对应 FeatureList** | 9.2.4 同步任务日志 |
| **对应 ER 实体** | 数据同步任务 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 任务列表行内「查看详情」需打开**任务详情页或右侧抽屉**，展示该条任务的完整信息及失败原因，便于排障与审计。
- 目标：详情区字段完整、失败原因可读；无额外提交操作，仅只读展示。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：飞书同步 → 任务 → 列表行内「查看详情」→ 右侧抽屉或独立详情页。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

- **布局**：右侧抽屉（推荐）或独立详情页；宽度建议 ≥ 480px，内容可滚动。
- **区块**：
  - **基础信息**：任务ID、数据类型（校招/事业编）、触发方式（自动/手动）、任务状态、开始时间、完成时间；若为手动触发，展示操作员（管理员ID或昵称）。
  - **同步结果**：新增数量、更新数量、跳过数量、失败数量（与列表一致，可表格或键值对）。
  - **失败原因**：若 fail_count > 0，展示失败原因（fail_reason）；可支持多行或前 N 条错误摘要（若后端有明细表可展示前 10 条等）；纯文本，可换行。
- **操作**：抽屉仅提供「关闭」；列表「重试」在列表行操作，不放在详情内也可（或详情底部提供「重试」按钮，逻辑同 M2.2）。

---

## 4. 字段规格表（详情展示）

| 字段显示名 | 字段键名 | 区域 | 类型 | 说明 |
|------------|----------|------|------|------|
| 任务ID | task_id | 详情 | bigint | PK |
| 配置ID | config_id | 详情 | bigint | 关联配置，可选展示 |
| 数据类型 | data_type | 详情 | enum | 校招/事业编 |
| 触发方式 | trigger_type | 详情 | enum | 自动/手动 |
| 任务状态 | status | 详情 | enum | 处理中/完成/失败 |
| 开始时间 | started_at | 详情 | datetime | — |
| 完成时间 | finished_at | 详情 | datetime | 未完成可为空 |
| 操作员 | operator_id | 详情 | — | 手动时有值，可展示管理员昵称 |
| 新增数量 | insert_count | 详情 | int | — |
| 更新数量 | update_count | 详情 | int | — |
| 跳过数量 | skip_count | 详情 | int | — |
| 失败数量 | fail_count | 详情 | int | — |
| 失败原因 | fail_reason | 详情 | string | 文本，可多行；多条失败可汇总或前 N 条 |

---

## 5. 业务逻辑与状态流转

- 详情数据来自任务表单条记录；失败原因直接展示 fail_reason 字段，若实现支持失败明细表可在此展示前若干条。
- 详情页/抽屉不修改任务状态，仅只读。

---

## 6. 异常与边界

- 任务进行中（状态=处理中）：完成时间为空，结果数量可为 0 或部分更新；前端可提示「任务执行中，请稍后刷新」。

---

## 7. 依赖与待定项

- **依赖**：M2.2 任务列表与数据同步任务表。
- **待定**：是否在详情内提供「重试」按钮（与列表行「重试」二选一或并存）。
