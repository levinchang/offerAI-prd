| **对应 ER 实体** | 飞书同步配置 |
| **对应时序图** | 时序图06_飞书多维表格定时增量同步到系统数据库 |

---

## 1. 需求背景与目标

- 校招、事业编数据来源于飞书多维表格，需在后台配置飞书应用凭证（App ID、App Secret、Token）、表格 ID、视图 ID 及字段映射，以便系统定时或手动从飞书拉取数据并写入本地库。
- 目标：管理员可分别维护「校招」「事业编」两套配置，并可测试连接是否可用；配置保存后立即生效（定时任务按新间隔执行，手动同步使用新配置）。

---

## 2. 角色与入口

- **角色**：管理员。
- **入口**：左侧菜单「飞书同步」→ 子菜单或 Tab「配置」；右侧主内容区展示配置列表及编辑入口。
- **登录态**：需已登录后台。

---

## 3. 页面结构与交互

- **布局**：左侧菜单 + 右侧主内容区。右侧为「配置」页。
- **配置列表**（表格）：
  - 行：每条配置一行，系统预置两条（数据类型=校招、数据类型=事业编），不可删除，仅可编辑。
  - 列：数据类型、飞书表格ID、飞书视图ID、同步间隔（分钟）、自动同步开关、上次同步时间、操作（编辑、测试连接）。
- **交互**：
  - I-01：点击「编辑」→ 打开编辑抽屉或右侧滑出表单，可修改该条配置的字段（见下表）；保存后关闭并刷新列表。
  - I-02：点击「测试连接」→ 弹出**测试连接**交互页/弹窗（见 3.1）；后端用当前配置调用飞书 API 拉取少量数据（如 1 条）；结果在弹窗内展示。
  - I-03：列表右上角「手动同步」→ 打开**手动同步**交互页/弹窗（见 3.2），可选择「校招」「事业编」或「全部」并确认后触发；逻辑见 M2.2。

### 3.1 测试连接交互（必须补全）

- **触发**：配置列表行内「测试连接」。
- **交互流程**：
  1. 点击后前端可展示 Loading（如「正在连接…」），禁用重复点击。
  2. 后端使用当前该条配置的 app_token（及 app_secret 若需刷新 token）调用飞书多维表格 API，拉取 1 条记录或仅校验权限。
  3. 前端收到结果后：
     - **成功**：弹窗/结果区展示「连接成功」，可附带简要说明（如「已成功读取飞书表格」）。
     - **失败**：弹窗/结果区展示后端返回的错误信息（如「Token 无效」「无表格访问权限」「App Secret 错误」等），不关闭弹窗直至用户关闭。
  4. 弹窗提供「关闭」按钮；无其他提交操作。

### 3.2 手动同步交互（必须补全）

- **触发**：配置页右上角「手动同步」按钮。
- **交互流程**：
  1. 点击后打开弹窗，选项：同步范围「校招」「事业编」「全部」；可展示简要说明（如「将按当前配置立即执行一次同步」）。
  2. 用户选择范围后点击「确认」→ 前端调用手动同步接口（参数：data_type 或 full）；后端创建一条 trigger_type=manual 的任务，状态=处理中，异步执行。
  3. 弹窗可关闭；任务列表（飞书同步 → 任务）中可见新任务，状态由处理中→完成/失败；可选：弹窗内提示「已创建同步任务，请到【任务】页查看进度」。
  4. 若接口返回错误（如配置未就绪），在弹窗内或 Toast 展示错误信息。

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 必填 | 长度/格式 | 取值来源 | 默认值 | 校验规则 | 错误提示 |
|------------|----------|----------|------|------|-----------|----------|--------|----------|----------|
| 数据类型 | data_type | 列表/表单 | enum | 是 | campus / civil | 系统固定，编辑时只读 | — | 仅两值其一 | — |
| 飞书 App ID | app_id | 编辑表单 | string | 是 | 非空，长度≤64 | 人工输入 | 空 | 非空 | 请输入飞书 App ID |
| 飞书 App Secret | app_secret | 编辑表单 | string | 是 | 非空，录入后脱敏展示 | 人工输入 | 空 | 非空；与 app_id 配合用于获取/刷新 tenant_access_token | 请输入飞书 App Secret |
| 飞书 App Token | app_token | 编辑表单 | string | 否 | 非空时建议脱敏展示 | 人工输入或由 App ID+Secret 刷新得到 | 空 | 若填写则用于直接请求多维表格；与 app_secret 二选一或并存由实现定 | 格式错误 |
| 飞书表格ID | table_id | 编辑表单 | string | 是 | 非空，长度≤100 | 人工输入 | 空 | 非空 | 请输入飞书表格ID |
| 飞书视图ID | view_id | 编辑表单 | string | 否 | 长度≤100 | 人工输入 | 空 | 若填写需合法 ID | — |
| 字段映射配置 | field_mapping | 编辑表单 | json/文本 | 是 | 合法 JSON，飞书列名→系统字段 | 人工配置或选默认模板 | 见 4.1 | 必须为合法 JSON；系统字段名需与 ER 一致 | 字段映射格式错误 |
| 同步间隔（分钟） | sync_interval_minutes | 编辑表单 | int | 是 | 5～1440（1 天） | 人工输入 | 60 | 5≤x≤1440；仅对定时任务生效 | 同步间隔需在 5～1440 分钟之间 |
| 自动同步开关 | auto_sync_enabled | 编辑表单 | bool | 是 | 开/关 | 人工选择 | true | — | — |

- **4.1 字段映射说明**：键为飞书多维表格列名（或列 ID），值为系统表字段名（如 company_name、job_title、city）。用于同步时把飞书每一列的取值写入系统对应字段。系统提供「校招默认」「事业编默认」两套默认映射模板（见 M2.2 同步逻辑），管理员可在此基础上修改；系统字段名需与「校招岗位」「事业编岗位」ER 字段一致。

---

## 5. 业务逻辑与状态流转

- **R-01**：系统初始化时，若不存在两条配置则自动创建（数据类型=campus、civil 各一），默认同步间隔 60 分钟、自动同步开；默认字段映射使用 M2.2 中的默认模板。
- **R-02**：保存配置后，定时任务按「同步间隔」和「自动同步开关」执行；若关闭自动同步，仅手动同步会拉取数据。
- **R-03**：「上次同步时间」在每次同步任务开始或结束时更新（见 M2.2）。

---

## 6. 异常与边界

- Token/Secret 无效或过期：测试连接与同步任务会失败，错误信息在测试连接弹窗或任务详情中展示，需管理员更新凭证。
- 表格/视图无权限：飞书 API 返回权限错误时，提示「无表格访问权限，请检查应用权限」。

---

## 7. 依赖与待定项

- **依赖**：飞书开放平台应用已创建，具备多维表格只读权限；后端需实现飞书 API 调用、tenant_access_token 获取（若用 app_id+app_secret）与字段映射解析。
- **待定**：字段映射是否提供可视化列选择器（从飞书拉取列列表），V1 可采用 JSON 文本 + 默认模板。
