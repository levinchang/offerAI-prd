# M1.2 管理员用户管理

| 项目 | 说明 |
|------|------|
| **功能名称** | 管理员账号管理与默认超级管理员 |
| **对应 FeatureList** | 9.1.1 后台登录 延伸 |
| **对应 ER 实体** | 管理员表（独立于前台用户表） |
| **对应时序图** | 与 M1.1 登录一致 |

---

## 1. 需求背景与目标

- 后台使用**用户名 + 密码**方式登录，与前台微信扫码登录完全隔离；管理员账号需可维护（列表、新增、编辑、禁用等）。
- 目标：系统默认有一个**超级管理员**账号，首次部署后可登录；支持多管理员、角色与权限扩展（V1 可为单角色「管理员」）；管理员列表与编辑由超级管理员或同权限管理员操作。

---

## 2. 默认超级管理员

- **默认账号**：用户名 `Admin`（注意大小写），默认密码 `admin1234`。
- **要求**：系统首次初始化时自动创建该账号；该账号为超级管理员，不可删除，仅可修改密码与部分资料；首次登录后强烈建议强制修改默认密码（可由实现或产品后续规定）。
- **登录方式**：与 M1.1 一致，用户名 + 密码，无验证码时仅靠账号密码校验。

---

## 3. 角色与入口

- **角色**：超级管理员或具备「管理员管理」权限的管理员。
- **入口**：左侧菜单「系统设置」→「管理员管理」；右侧主内容区为管理员列表；新增/编辑为抽屉或独立页。
- **登录态**：需已登录后台。

---

## 4. 页面结构与交互

- **布局**：左侧菜单 + 右侧主内容区。
- **管理员列表**：列：用户名、姓名/备注、状态（启用/禁用）、最后登录时间、操作（**编辑**、禁用/启用）。超级管理员行不展示「删除」。列表右上角**「新增管理员」**按钮，点击后打开新增抽屉/页。
- **新增管理员（创建）**：点击「新增管理员」→ 打开**新增管理员**抽屉或独立页。表单字段：用户名（必填，4～32 字符，唯一）、密码（必填，6～32）、姓名/备注（选填）、状态（默认启用）。底部「取消」「保存」；保存成功后关闭并刷新列表，该账号可登录。
- **编辑管理员**：点击行内「编辑」→ 打开**编辑管理员**抽屉或独立页。表单：用户名（超级管理员为只读，其他可只读或按需禁止修改）、姓名/备注（可改）、状态（可改，超级管理员不可改为禁用）、密码（选填，不填则不修改，填则更新）。底部「取消」「保存」；超级管理员行仅能改密码与备注。
- **禁用/启用**：行内「禁用」/「启用」→ 二次确认后更新状态；不可禁用当前登录的自己；超级管理员不可被禁用。

---

## 5. 字段规格表

| 字段显示名 | 字段键名 | 区域 | 类型 | 必填 | 长度/格式 | 说明 |
|------------|----------|------|------|------|-----------|------|
| 用户名 | username | 列表/表单 | string | 是 | 4～32，字母数字下划线 | 登录用，唯一 |
| 密码 | password | 表单 | string | 新增必填；编辑选填 | 6～32 | 存储须哈希，编辑时不展示明文，填则更新 |
| 姓名/备注 | display_name | 列表/表单 | string | 否 | ≤50 | 展示用 |
| 状态 | status | 列表/表单 | enum | — | 启用/禁用 | 禁用后不可登录 |
| 是否超级管理员 | is_super | 系统 | bool | — | — | 仅一条为 true，不可删、不可禁用、不可改用户名 |
| 最后登录时间 | last_login_at | 列表 | datetime | — | — | 选填 |

---

## 6. 业务逻辑与状态流转

- **R-01**：登录校验见 M1.1；仅状态=启用的管理员可登录。
- **R-02**：超级管理员由系统初始化创建（Admin / admin1234），is_super=true；不可删除、不可禁用、不可修改用户名。
- **R-03**：同一用户名不可重复；禁用后立即生效，该账号下次请求即视为未登录。

---

## 7. 异常与边界

- 唯一超级管理员被误操作：通过 is_super 与逻辑限制，前端与后端均不提供「删除」或「禁用」入口。
- 忘记密码：可由其他管理员在「编辑」中为其重置密码（V1）；或后续做「忘记密码」流程。

---

## 8. 依赖与待定项

- **依赖**：管理员表；M1.1 登录接口与鉴权。
- **待定**：是否支持角色/权限细分（如仅飞书同步、仅岗位维护）；V1 可为全部管理员同权。
