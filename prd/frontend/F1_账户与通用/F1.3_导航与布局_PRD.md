# F1.3 导航与布局

| 项目 | 说明 |
|------|------|
| **功能名称** | 顶部导航与整体布局 |
| **对应 FeatureList** | 1.3.1 主导航、1.3.2 会员状态角标 |
| **对应 ER 实体** | 无（纯前端布局） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 前台为 C 端扁平化风格，固定顶部导航，无左侧菜单；用户可快速在「校招」「事业编」「面试资料」「投递看板」「个人中心」间切换，并看到登录与会员状态。
- 目标：主导航清晰；未登录显示「求职者登录」，已登录显示用户头像/昵称及会员类型；到期前 7 天高亮提醒。

---

## 2. 角色与入口

- **角色**：所有前台用户（访客、注册用户、会员用户）。
- **入口**：所有前台页面共用同一顶部导航；首屏即见。

---

## 3. 页面结构与交互

- **布局**：整站统一。顶部一条通栏，背景白或浅灰，下边框分隔；主内容区在下方全宽展示。
- **顶部结构**（参考扁平化竞品）：
  - **左侧**：Logo（如 offerAI 或 Offer信息站），可点击回首页。
  - **中部**：主导航链接（横向）：**校招信息表** / **事业编国企表** / **面试资料** / **投递看板**（仅登录后显示）/ **个人中心**。当前页对应项高亮（如红色字或下划线）。
  - **右侧**：「官方小程序」（灰色按钮+小图标）、「企业入口」（白底红框，跳转后台或合作页）、**「求职者登录」**（红底白字，未登录时显示）；已登录时改为头像+昵称或下拉菜单（含「个人中心」「退出登录」）。
- **会员状态角标**（Should）：在「个人中心」旁或用户下拉菜单内展示当前会员类型（校招会员/事业编会员/双会员/无）；到期前 7 天用红色或橙色角标/文案提醒「即将到期」。
- **交互**：
  - I-01：点击主导航项 → 跳转对应列表页或首页。
  - I-02：点击「求职者登录」→ 弹出微信扫码登录（F1.1）；已登录则点击「个人中心」或头像下拉进入个人中心。
  - I-03：投递看板：未登录时可不展示该导航项，或展示但点击后先弹登录。

---

## 4. 字段规格表

无表单字段；展示数据来源于登录态与会员接口（会员类型、到期时间）。

---

## 5. 业务逻辑与状态流转

- **R-01**：投递看板、个人中心为登录后能力；未登录时点击需登录能力先弹扫码，再进入目标页。
- **R-02**：会员角标数据与个人中心权益一致，到期前 7 天在导航栏与个人中心同时提醒。

---

## 6. 异常与边界

- 移动端：导航可收缩为汉堡菜单 + 抽屉，具体由前端实现；PRD 不约束。
- 窄屏：主导航可横向滚动或折叠，保证「求职者登录」/用户区可见。

---

## 7. 依赖与待定项

- **依赖**：登录态接口、会员到期接口（用于角标与提醒）。
- **待定**：是否增加「首页」独立导航项（当前可为 Logo 点击回首页）。
