# 前台功能 PRD 索引

## 设计规范（与后台区分）

- **风格**：**扁平化**，参考 offerAI 竞品：简洁形状、纯色、清晰边框，无复杂阴影与渐变。
- **主色**：红色用于主 CTA（立即开通、求职者登录、投递链接）；蓝色用于次要按钮与链接；灰色用于边框与辅助文案；标签按类型区分（如事业单位-橙、合资/外企-蓝）。
- **布局**：**固定顶部导航**（Logo 左 + 主导航中 + 用户操作右）+ 主内容区；无左侧菜单。
- **导航**：校招信息表 / 事业编国企表 / 面试资料 / 投递看板（登录后） / 个人中心；右侧「官方小程序」「企业入口」「求职者登录」。
- **表格与筛选**：列表页上方为搜索框 + 多条件筛选（下拉/日期/开关）；表格列含「会员操作专区」（投递状态、编辑备注、查看公告原文、查看详情等）。
- **PRD 模板**：与后台一致（Header → 需求背景 → 角色与入口 → 页面与交互 → 字段规格 → 业务逻辑 → 异常与边界 → 依赖）。
