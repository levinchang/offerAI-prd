# F2.1 首页落地页

| 项目 | 说明 |
|------|------|
| **功能名称** | 首页/落地页 |
| **对应 FeatureList** | 2.1.1 产品价值 Banner、2.1.2 会员权益对比表、2.1.3 立即开通按钮、2.1.4 UTM 参数识别 |
| **对应 ER 实体** | 无（展示与埋点） |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 从小红书等渠道引流用户，首屏需快速传达价值并引导注册与付费。
- 目标：展示三大核心功能（校招表/事业编表/面试资料）及数据量概览；清晰对比「免费 vs 会员」权益，突出投递链接解锁；全站明显的「立即开通会员」CTA；识别并记录 UTM 参数用于渠道追踪。

---

## 2. 角色与入口

- **角色**：访客、注册用户、会员用户。
- **入口**：站点根路径或「首页」；从外部分享链接带 UTM 进入时同样展示本页并记录 UTM。

---

## 3. 页面结构与交互

- **布局**：扁平化、留白适中。自上而下：Banner 区 → 权益对比区 → CTA 区；可选底部简短 footer。
- **区域**：
  - **产品价值 Banner**：标题与副标题（如「一站式校招与事业编信息」）；三大功能入口卡片或图标+文案（校招信息表、事业编国企表、面试资料）；数据量概览（如「已收录 XX 条校招岗位」「XX 条事业编公告」），数字可动态拉取。
  - **会员权益对比表**：表格或卡片对比「免费用户」与「会员」：浏览信息、投递链接/原文链接、投递看板、简历管理、分组等；核心差异项（投递链接解锁）用红色或加粗强调。
  - **付费引导**：醒目按钮「立即开通会员」（红底白字）；点击进入套餐选择页（F2.2 / F7.1）。首页以外各信息页也需有相同或相似 CTA（如列表页顶部或侧边）。
- **UTM 识别**（Should）：进入页时从 URL 读取 utm_source、utm_campaign、utm_content 等，前端上报或随注册/关键行为上报至后端，写入用户来源；不在页面上直接展示。
- **交互**：
  - I-01：点击三大功能 → 跳转校招列表/事业编列表/面试资料列表。
  - I-02：点击「立即开通会员」→ 跳转套餐选择页。
  - I-03：已登录会员可隐藏或弱化「立即开通」主 CTA，改为「进入校招表」等。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 校招岗位数量 | campus_job_count | Banner | number | 可选动态接口 |
| 事业编公告数量 | career_job_count | Banner | number | 可选动态接口 |
| UTM 参数 | utm_source 等 | URL/埋点 | string | 仅识别与上报，不展示 |

---

## 5. 业务逻辑与状态流转

- **R-01**：UTM 在首访或注册时写入用户来源；同一用户多次带不同 UTM 的规则（首次优先或最近一次）由产品/运营约定。
- **R-02**：数据量概览可为缓存或定时更新，非实时亦可。

---

## 6. 异常与边界

- 无数据量接口时：Banner 可展示静态文案「海量岗位持续更新」。
- 移动端：Banner 与对比表需适配竖屏，CTA 保持醒目。

---

## 7. 依赖与待定项

- **依赖**：套餐选择页（F2.2）；可选数据量接口、UTM 上报接口。
- **待定**：是否增加用户评价/背书区块（Nice to have，见 F2.2）。
