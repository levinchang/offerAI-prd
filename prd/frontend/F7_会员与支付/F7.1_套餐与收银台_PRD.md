# F7.1 套餐与收银台

| 项目 | 说明 |
|------|------|
| **功能名称** | 套餐选择与收银台下单支付 |
| **对应 FeatureList** | 7.1.1～7.1.5 商品体系（会员 SKU、资料 SKU、优惠码）、7.2.1～7.2.3 下单与支付渠道 |
| **对应 ER 实体** | 订单、商品/SKU、支付 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户从套餐选择页选择会员或资料商品，进入收银台完成订单创建与支付；支持优惠码抵扣；支持微信支付与支付宝支付（PC 扫码、H5 拉起）。
- 目标：套餐选择页展示校招/事业编/双会员及价格（F2.2 已述）；收银台展示订单信息、应付金额、优惠码输入、支付方式选择（微信/支付宝）；创建订单后 PC 展示支付二维码或 H5 调起支付，支付成功后跳转结果页（F7.2）。

---

## 2. 角色与入口

- **角色**：访客、注册用户（未登录购买时需先登录或支付时拉登录）。
- **入口**：套餐选择页选择套餐后「立即购买」→ 收银台；面试资料阅读器/详情「立即购买」→ 收银台（资料单品）。收银台为独立页面或整页区块；**资料订单**与**会员订单**在同一收银台通过订单类型（商品类型）区分，支付结果页可根据订单类型跳转至「我的资料」或会员权益页。

---

## 3. 页面结构与交互

### 3.1 套餐选择页

- 见 F2.2：校招会员 19.9/年、事业编会员 19.9/年、双会员组合价（可配）；选择后进入收银台并携带商品 ID、数量。

### 3.2 收银台

- **布局**：扁平化。订单摘要（商品名称、规格、数量、单价、小计）；优惠码输入框 + 「使用」按钮，抵扣后展示「已减 XX 元」；应付金额；支付方式：微信支付、支付宝支付（图标或卡片选择）；「提交订单」或「去支付」主按钮（红色）。
- **流程**：点击去支付 → 创建订单（待支付）；根据支付方式展示二维码（PC 微信）或跳转/调起（支付宝、H5 微信）；轮询或回调后跳转支付结果页。
- **优惠码**（Should）：输入优惠码并点击「使用」，后端校验（折扣/固定减、有效期、使用次数）；成功则更新应付金额并展示抵扣明细；失败提示「优惠码无效或已过期」。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 商品名称 | product_name | 收银台 | string | 会员类型或资料标题 |
| 数量/单价/小计 | quantity, price, amount | 收银台 | number | — |
| 优惠码 | promo_code | 收银台 | string | 输入后校验 |
| 抵扣金额 | discount_amount | 收银台 | decimal | 优惠码生效后 |
| 应付金额 | pay_amount | 收银台 | decimal | 元 |
| 支付方式 | pay_channel | 收银台 | enum | 微信/支付宝 |
| 订单号 | order_no | 支付结果 | string | 创建订单后返回 |

---

## 5. 业务逻辑与状态流转

- **R-01**：订单创建后状态为「待支付」；支付成功由回调更新为「已支付」并发放权益（F7.2）；超时未支付订单可自动关闭（如 30 分钟）。
- **R-02**：同一订单重复支付（幂等）由后端保证；前端轮询订单状态或依赖支付回调跳转结果页。
- **R-03**：优惠码校验在后端；前端仅展示输入与结果，不信任前端计算金额。

---

## 6. 异常与边界

- 库存/限购：若会员或资料有库存或限购，创建订单时校验，失败提示。
- 支付取消：用户取消支付后停留在收银台或返回套餐页，订单保留待支付一段时间。

---

## 7. 依赖与待定项

- **依赖**：订单创建接口、支付下单接口（微信/支付宝）、支付结果轮询或回调；优惠码校验接口。
- **待定**：是否支持购物车多商品合并支付，V1 建议单商品下单。
