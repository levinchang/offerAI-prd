# Offer信息站 - 前台页面原型

基于前台 PRD（F1～F8）生成的静态页面原型，参考 [offer先生](https://www.offerxiansheng.com/info) 的**数据驱动、工具感**与 **UI/UX PRO MAX** 规范，采用 HTML + Tailwind CSS + Lucide 图标 + 原生 JS，无后端依赖。

## 设计规范（与后台不共用）

- **风格**：专业、数据优先；清晰卡片与统计看板，适度阴影与圆角；符合 UI/UX PRO MAX（无 emoji 图标、SVG/Lucide、hover 反馈、对比度）。
- **主色**：主 CTA 红色 `#E63946`（求职者登录、立即开通、点击投递）；辅助色深蓝 `#1D3557` / `#457B9D`（链接、信息层级）；背景 `#F8FAFC`，卡片白底。
- **字体**：DM Sans（正文与标题），清晰易读。
- **布局**：固定顶部导航（Logo+主导航左，官方小程序/企业入口/求职者登录右）+ 主内容区；首页含**统计数据看板**、**产品介绍**、**使用引导（三步）**、核心功能卡片、会员权益对比、CTA。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 主站框架：顶部导航 + 主内容区，多页切换（首页、校招列表、事业编列表、面试资料、投递看板、个人中心、套餐选择等）；含登录弹窗占位、权益弹窗占位、收银台占位 |

## 与 PRD 对应关系

- **F1.1** 微信扫码登录 → 顶部「求职者登录」点击弹出登录弹窗（二维码占位）
- **F1.2** 个人中心 → 主导航「个人中心」→ 基本信息、我的权益、我的订单
- **F1.3** 导航与布局 → 顶部通栏：校招信息表 / 事业编国企表 / 面试资料 / 投递看板 / 个人中心；右侧 官方小程序、企业入口、求职者登录
- **F2.1** 首页落地页 → 默认页：价值 Banner、权益对比、立即开通 CTA
- **F2.2** 付费墙与套餐 → 权益弹窗占位；「套餐选择」页：校招/事业编/双会员
- **F3.1** 校招列表与筛选 → 搜索框 + 筛选区（招聘类型、企业类型、行业、城市等）+ 表格（含会员操作专区）
- **F3.2** 校招权限与个性化 → 行内投递链接（点击投递/🔒）、投递状态下拉、编辑备注、查看公告原文、查看校招详情
- **F4.1 / F4.2** 事业编列表与权限 → 列表 + 筛选 + 详情展开 + 原文链接与会员操作
- **F5.1** 面试资料 → 卡片列表 + 详情页占位（预览 3 页、购买）
- **F6.1～F6.5** 投递看板与简历 → 看板视图 + 列表视图切换；简历库入口；分组筛选；新增/编辑投递记录占位
- **F7.1** 套餐与收银台 → 套餐选择页、收银台占位（订单摘要、优惠码、支付方式）
- **F7.2** 支付结果 → 支付成功/失败结果页占位
- **F8.1** 新用户与渠道 → 首次浮窗、Onboarding 占位可在首页或列表页展示

## 使用方式

1. 用浏览器直接打开 `index.html`
2. 顶部导航切换：校招、事业编、面试资料、投递看板、个人中心
3. 点击「求职者登录」弹出登录弹窗；点击「立即开通会员」进入套餐选择页
4. 校招列表页可点击行内「点击投递」、投递状态下拉、编辑备注等（原型无真实提交）
5. 投递看板可切换看板/列表视图，简历库从个人中心或看板入口进入
