# F5.1 面试资料列表与详情

| 项目 | 说明 |
|------|------|
| **功能名称** | 面试资料列表、详情、预览与购买 |
| **对应 FeatureList** | 5.1.1～5.1.2 列表与搜索筛选、5.2.1～5.2.4 详情与预览、购买、下载 |
| **对应 ER 实体** | 面试资料、订单、用户资料权限 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户浏览面试资料卡片列表，通过搜索与筛选定位目标；进入详情页查看简介与目录，免费预览前 3 页，未购用户第 4 页起遮罩+购买引导；已购用户可全文阅读与带水印下载。
- 目标：卡片列表展示封面图、标题、行业/企业标签、价格、购买量、已购角标；详情页展示标题/简介/目录/标签/购买人数与购买按钮；预览前 3 页、第 4 页起遮罩；购买后全文阅读与阅读位置记忆；已购可下载 PDF（带水印）。

---

## 2. 角色与入口

- **角色**：访客、注册用户、已购用户。
- **入口**：顶部导航「面试资料」；首页入口。详情页由列表点击进入。

---

## 3. 页面结构与交互

### 3.1 资料列表

- **布局**：扁平化卡片网格。每卡：封面图、标题、行业/企业标签（标签色）、价格、购买量、已购角标（已购用户显示「已购」）。
- **搜索与筛选**：按企业名称/行业/岗位类型搜索与筛选；筛选为多选或下拉。
- **交互**：点击卡片 → 进入资料详情页。

### 3.2 资料详情页

- **区域**：标题、简介、目录（可选）、标签、购买人数、「购买」按钮（未购）或「继续阅读」（已购）；可选「分享」入口（F5.2）。
- **预览区**：内嵌 PDF 或图片预览；任何用户（含访客）可看前 3 页；第 4 页起模糊遮罩 + 文案「购买解锁全文」+ 购买按钮。后端对未购用户不返回第 4 页及以后内容（防绕过）。
- **购买后**：全文可读；阅读位置持久化（记住上次阅读页）；已购用户可下载 PDF，后端生成时添加水印（用户微信ID+订单号+时间）（Should）。

### 3.3 下载

- **带水印下载**（Should）：已购用户点击「下载」→ 请求带水印 PDF 生成或直链；下载文件自动包含水印信息。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 封面图 | cover_url | 列表 | string | URL |
| 标题 | title | 列表/详情 | string | — |
| 行业/企业标签 | tags | 列表/详情 | array | 标签展示 |
| 价格 | price | 列表/详情 | decimal | 元 |
| 购买量 | purchase_count | 列表/详情 | number | — |
| 已购 | is_purchased | 列表/详情 | boolean | 当前用户 |
| 简介/目录 | description, toc | 详情 | text | — |
| 预览页数 | preview_pages | 详情 | number | 默认 3 |
| 阅读位置 | read_position | 详情 | number | 已购用户，页号 |

---

## 5. 业务逻辑与状态流转

- **R-01**：完整内容（第 4 页起）仅对已购用户返回；预览页数由后台资料配置。
- **R-02**：购买成功后写入 user_doc_access 或等价权益，请求全文/下载时校验。
- **R-03**：阅读位置由前端上报或本地存储，可选服务端持久化。

---

## 6. 异常与边界

- 资料下架：详情页提示「该资料已下架」或列表不展示。
- 预览加载失败：提示「加载失败，请重试」。

---

## 7. 依赖与待定项

- **依赖**：资料列表/详情接口、预览内容接口、购买与权益接口（F7）、下载接口。
- **待定**：目录是否支持锚点跳转（V1 可不做）。
