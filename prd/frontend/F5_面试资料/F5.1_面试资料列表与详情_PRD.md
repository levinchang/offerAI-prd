# F5.1 面试资料列表与详情

| 项目 | 说明 |
|------|------|
| **功能名称** | 面试资料商城与我的资料、列表筛选、详情/阅读器、预览与购买 |
| **对应 FeatureList** | 5.1.1～5.1.2 列表与搜索筛选、5.2.1～5.2.4 详情与预览、购买、下载 |
| **对应 ER 实体** | 面试资料、订单、用户资料权限 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户可在「资料商城」浏览与筛选面试资料并购买，在「我的资料」集中查看已购资料并阅读；未购资料支持预览前 N 页（N 可配置），之后遮罩+购买引导，支付方式参考常见收银（如淘宝式，不必过重）。
- 目标（V1）：**资料商城**与**我的资料**双 Tab 结构；商城侧：企业模糊搜索、岗位筛选、行业筛选（竖或横菜单，行业由后台可维护）；列表卡片展示封面、标题、行业/企业、价格、已购角标；未购点击进入阅读器可预览前 N 页，之后展示购买引导区块并弹出支付（F7）；已购用户全文阅读与阅读位置记忆，**支持下载带个人水印的 PDF（可自行打印）**。
- 规划（V2）：支持从腾讯文档/飞书文档等云文档一键导入或刷新资料内容，并抽取目录结构用于左侧/右侧大纲导航。

---

## 2. 角色与入口

- **角色**：访客、注册用户、已购用户。
- **入口**：顶部导航「面试资料」；首页入口。阅读器/详情由列表或「我的资料」点击进入。

---

## 3. 页面结构与交互

### 3.1 面试资料页整体

- **双 Tab**：**资料商城**、**我的资料**。默认展示资料商城；我的资料展示当前用户已购资料列表（知识库式），带「已购」标识与最近阅读等，选择一项在右侧或新开阅读器阅读。

### 3.2 资料商城

- **布局**：顶部企业**模糊搜索**（公告/资料标题或企业名）；**岗位**筛选（下拉或快捷 pill，选项来自后台维护的岗位枚举）；**行业**筛选：竖排菜单或横向 Tab（如：全部、互联网、金融、制造业、事业单位等），行业枚举由**后台可维护**（见 M5/字典），仅展示已启用的行业。
- **列表**：卡片网格。每卡：封面图、标题、行业/企业标签、价格、已购角标（已购显示「已购」）。点击卡片 → 打开阅读器（未购为预览+购买引导，已购为全文）。

### 3.3 我的资料

- **布局**：左侧已购资料列表（知识库式），每项带「已购」标识、最近阅读时间等；右侧为阅读区或占位「选择左侧资料开始阅读」。点击左侧某项 → 右侧加载该资料阅读器。

### 3.4 阅读器（详情/预览与购买）

- **区域**：标题、只读正文区；未购用户仅展示前 N 页（N 由后台资料配置），之后为**购买引导区块**（如「预览已结束」「购买解锁全文」+ 价格 +「立即购买」按钮）。
- **交互**：点击「立即购买」→ 弹出支付弹窗（参考 F7 收银台/资料订单），选择支付方式并确认支付；支付成功后该资料加入已购，阅读器遮罩移除、全文可读。
- **购买后（V1）**：全文可读；阅读位置持久化；支持从阅读器点击「下载 PDF（含个人水印）」按钮，下载到本地后用户可在本地 PDF 查看器中自行打印。

### 3.5 下载与打印

- **下载（V1 Must）**：已购用户点击「下载」→ 后端基于原始 PDF 生成或返回**带个人水印的 PDF**（如手机号/用户ID+订单号+日期等），文件所有页面均带半透明水印；未购用户点击下载时引导先购买。
- **打印（V1）**：不单独做“打印权限”控制，用户在本地打开带水印 PDF 后可自行打印，打印内容中仍保留水印；若后续需要进一步限制打印，可在 V2 方案中补充。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 封面图 | cover_url | 列表 | string | URL |
| 标题 | title | 列表/阅读器 | string | — |
| 行业/企业标签 | tags, industry | 列表/筛选 | array/string | 行业由后台可维护；企业可模糊搜索 |
| 岗位 | job_type / position | 筛选 | string/enum | 岗位筛选，可与后台资料标签一致 |
| 价格 | price | 列表/购买引导 | decimal | 元 |
| 购买量 | purchase_count | 列表 | number | — |
| 已购 | is_purchased | 列表/我的资料 | boolean | 当前用户 |
| 简介/目录 | description, toc | 阅读器 | text | — |
| 预览页数 | preview_pages | 阅读器 | number | 后台配置，默认 3 |
| 阅读位置 | read_position | 阅读器 | number | 已购用户，页号 |

---

## 5. 业务逻辑与状态流转

- **R-01**：完整内容（第 4 页起）仅对已购用户返回；预览页数由后台资料配置。
- **R-02**：购买成功后写入 user_doc_access 或等价权益，请求全文/下载时校验。
- **R-03**：阅读位置由前端上报或本地存储，可选服务端持久化。
- **R-04（V1）**：下载接口仅对已购用户开放；生成的 PDF 均带个人水印（每页），水印内容至少包括用户标识与订单号，以便追溯。

---

## 6. 异常与边界

- 资料下架：详情页提示「该资料已下架」或列表不展示。
- 预览加载失败：提示「加载失败，请重试」。

---

## 7. 依赖与待定项

- **依赖**：资料列表/详情接口、预览内容接口、**资料订单与支付**（F7 收银台支持资料单品，见 F7.1）、下载接口；行业/岗位枚举与后台可维护（M5 或字典 M8）。
- **待定**：目录是否支持锚点跳转（V1 可不做）。资料单独支付与会员支付在同一收银台，通过订单类型区分（会员/资料）。
