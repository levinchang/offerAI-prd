# F5.2 面试资料分享

| 项目 | 说明 |
|------|------|
| **功能名称** | 面试资料分享链接 |
| **对应 FeatureList** | 5.3.1 分享资料页 |
| **对应 ER 实体** | 用户、邀请码/分享参数 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户可将资料页分享给他人，分享链接带邀请码；被分享者打开可免费看前 3 页，点击购买引导付费，便于传播与转化。
- 目标：详情页提供「分享」入口，复制带邀请码的链接；新用户通过该链接进入仍为「免费预览 3 页 + 购买引导」，不改变预览逻辑。

---

## 2. 角色与入口

- **角色**：已登录用户（分享方）；访客/新用户（被分享方）。
- **入口**：面试资料详情页「分享」按钮或图标。

---

## 3. 页面结构与交互

- **分享入口**：详情页点击「分享」→ 弹窗或下拉展示「复制链接」；链接格式包含资料 ID 与邀请码（如 inviter_uid 或 code）。复制成功提示「链接已复制」。
- **被分享者**：打开链接进入同一资料详情页；若未登录可先浏览预览 3 页，点击购买时引导登录再支付；邀请码写入用于后续统计或激励（若做邀请裂变）。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 说明 |
|------------|----------|------|
| 分享链接 | share_url | 含 doc_id、invite_code 等 |
| 邀请码 | invite_code | 可选，用于统计/返利 |

---

## 5. 业务逻辑与状态流转

- **R-01**：分享链接与普通详情页共用同一路由，通过 query 区分邀请码；后端可记录「通过某邀请码访问」用于后续分析或奖励。
- **R-02**：预览与购买逻辑与 F5.1 一致，不因分享链接而放宽权限。

---

## 6. 异常与边界

- 链接失效：若邀请码过期或无效，仍可正常进入详情页，仅不记录邀请关系。

---

## 7. 依赖与待定项

- **依赖**：详情页路由支持 query；可选邀请码生成与记录接口。
- **待定**：邀请返利规则在 V1.1 或小程序实现，Web V1 仅做链接分享与参数记录。
