# F3.2 校招会员引导与转化

| 项目 | 说明 |
|------|------|
| **功能名称** | 校招表页会员引导条展示与点击转化 |
| **对应 FeatureList** | 2.2.x 付费墙与转化 |
| **对应 ER 实体** | 用户、会员权益 |
| **用户故事** | 作为未开通校招会员的用户，我希望在校招表页看到清晰的会员权益引导，并能一键去登录或开通；作为已开通用户，我希望不再被强引导，或仅看到权益确认文案。 |

---

## 1. 验收标准（可闭环测试）

- [ ] **AC1** 未登录时，统计区下方展示会员引导条/卡片，含权益文案 + 主按钮「立即开启会员权益」。
- [ ] **AC2** 已登录未开通校招会员时，同上展示引导条 + 「立即开启会员权益」。
- [ ] **AC3** 已登录已开通校招会员时，不展示上述引导条，或仅展示弱提示「您已是校招会员，可查看投递链接、使用投递看板与简历管理」。
- [ ] **AC4** 未登录点击「立即开启会员权益」→ 弹出登录弹窗（F1.1）；用户完成登录后**自动跳转到会员开通页**（套餐选择页），不留在当前列表页。
- [ ] **AC5** 已登录未开通点击「立即开启会员权益」→ 直接跳转到会员开通页。
- [ ] **AC6** 已开通用户不展示 CTA 按钮，无跳转行为。

---

## 2. 角色与入口

- **角色**：访客（未登录）、已登录未开通校招会员、校招会员。
- **入口**：校招表页，统计卡片与筛选区之间的固定区域。
- **依赖**：F1.1 微信扫码登录、会员开通页（套餐选择）路由。

---

## 3. 页面与交互

### 3.1 展示条件（三态）

| 状态 | 引导条展示 | 主按钮 |
|------|------------|--------|
| 未登录 | 展示 | 「立即开启会员权益」 |
| 已登录未开通校招会员 | 展示 | 「立即开启会员权益」 |
| 已登录已开通校招会员 | 不展示 / 或弱提示文案 | 无 |

### 3.2 文案建议

- 引导条：示例「购买校招会员享受求职优享服务，每日实时更新，可管理投递进度、使用投递看板与简历库。」
- 已开通弱提示：示例「您已是校招会员，可查看投递链接、使用投递看板与简历管理。」

### 3.3 点击行为

- **未登录** → 点击「立即开启会员权益」→ 打开登录弹窗；**登录成功后**关闭弹窗并**跳转至会员开通页**（与从列表行点击投递链接未登录时的下一跳一致）。
- **已登录未开通** → 点击「立即开启会员权益」→ 直接跳转会员开通页。
- **已开通** → 无 CTA，不跳转。

---

## 4. 业务规则

- **R-01** 引导条仅根据「是否登录」「是否已开通校招会员」两维判断，与事业编会员无关。
- **R-02** 从本页引导触发的登录，登录成功后的下一跳固定为会员开通页，不在校招表页停留。

---

## 5. 异常与边界

- 会员开通页未就绪时，可先跳转至占位页或套餐列表，后续由 F2.2/F7 补齐。

---

## 6. 依赖与待定项

- **依赖**：F1.1 登录弹窗、会员开通页（套餐选择）路由。
- **待定**：无。
