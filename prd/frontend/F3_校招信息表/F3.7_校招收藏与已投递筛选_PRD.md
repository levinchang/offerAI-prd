# F3.7 校招收藏与已投递筛选

| 项目 | 说明 |
|------|------|
| **功能名称** | 我的收藏入口、仅看收藏筛选、已投递进度筛选 |
| **对应 FeatureList** | 3.4.1～3.4.2 收藏、3.5.1～3.5.2 投递标记与已投过滤 |
| **对应 ER 实体** | 用户、收藏、投递记录 |
| **用户故事** | 作为已登录用户，我希望有固定入口查看自己收藏的校招岗位，并在校招表页能「仅看收藏」；作为已登录用户，我希望按投递进度（已投递/笔试/面试/Offer）筛选列表，未付费用户也能看到该筛选项并被引导付费。 |

---

## 1. 验收标准（可闭环测试）

- [ ] **AC1** 登录后，**个人中心**有「我的收藏」区块（校招收藏），点击进入收藏列表或筛选为仅收藏的校招岗位。
- [ ] **AC2** 校招表页**首行**提供「仅看收藏（我的收藏）」与**求职进度**下拉，**全员可见**（未登录、未开会员也展示）；未登录点击→弹登录，未开会员点击→弹开通提醒；登录且开会员后筛选生效。
- [ ] **AC3** 求职进度选项：全部、待投递、已投递、待笔试、已笔试、一面、二面、三面、已offer、未通过（与操作专区「标记进度」枚举一致）。
- [ ] **AC4** 未开会员选择某进度或勾选仅看收藏时：弹开通提醒或列表占位；点击行内投递链接/操作专区时按 F3.6 引导开通。
- [ ] **AC5** 已开会员：求职进度与仅看收藏正常筛选；列表可正常使用投递链接与操作专区。
- [ ] **AC6** 收藏/取消收藏在列表行内操作，见 F3.6；收藏数据与「我的收藏」「仅看收藏」一致。

---

## 2. 角色与入口

- **角色**：所有用户可见「求职进度」「我的筛选分组」「仅看收藏」入口；使用筛选结果与行内操作需登录且开会员（未登录/未开会员点击时弹登录或开通提醒）。
- **入口**：校招表页**首行**求职进度、我的筛选分组、仅看收藏；个人中心「我的收藏」区块。
- **依赖**：收藏接口、投递记录接口（F6.2）、个人中心页（F1.2）、F3.5 列表、F3.6 行内收藏。

---

## 3. 页面与交互

### 3.1 我的收藏入口

- **个人中心**：登录后在个人中心增加「我的收藏」区块；点击后进入「我的收藏」页或 Tab，内容为校招（及可选事业编）收藏列表；可展示收藏数量 N。
- **校招表页**：首行提供「仅看收藏（N）」勾选/入口，全员可见；未登录勾选→弹登录，未开会员→弹开通提醒；登录且开会员后勾选即筛选仅收藏岗位。

### 3.2 仅看收藏

- 交互：校招表页勾选「仅看收藏」或点击「我的收藏（N）」→ 列表筛选条件增加「当前用户已收藏」→ 刷新列表。
- 与行内收藏联动：在列表行内取消收藏后，「仅看收藏」下的列表实时或刷新后移除该条；收藏数 N 更新。

### 3.3 求职进度筛选

- 筛选项：**求职进度**：全部、待投递、已投递、待笔试、已笔试、一面、二面、三面、已offer、未通过（与操作专区「标记进度」及投递看板阶段一致）。
- 可见性：**全员可见**（首行）；未登录选择/点击→弹登录；未开会员选择→弹开通提醒；登录且开会员后筛选生效。
- 数据依据：当前用户在该岗位的投递记录阶段（用户在操作专区「标记进度」维护，非由点击投递链接自动写入）。

### 3.4 与投递看板的关系

- 进度数据与 F6 投递看板一致；在列表筛选「已投递」等即筛选「当前用户在该进度下的投递记录对应的校招岗位」。
- 个人中心「我的投递」/投递看板为完整管理视角；校招表进度筛选为在列表内快速缩小范围，两者互补。

---

## 4. 业务规则

- **R-01** 收藏按用户+岗位（校招岗位 ID）维度存储；「仅看收藏」即筛选当前用户收藏的校招岗位。
- **R-02** 进度筛选以「当前用户是否有该岗位的投递记录且阶段=所选值」为准；仅登录用户可见与使用。
- **R-03** 未付费用户使用进度筛选时，列表可展示条数或受限数据，点击行内操作时引导开通，不暴露真实投递/原文链接。

---

## 5. 异常与边界

- 收藏列表为空：个人中心「我的收藏」或校招表「仅看收藏」下展示空状态「暂无收藏」。
- 某进度下无记录：列表为空，提示「该进度下暂无岗位」或等价文案。

---

## 6. 依赖与待定项

- **依赖**：收藏接口、F6.2 投递记录、F1.2 个人中心、F3.5 列表、F3.6 行内收藏与权限。
- **待定**：「我的收藏」是独立页还是个人中心内 Tab 由产品定；未付费用户选择进度后列表是展示条数还是受限列表由产品定。
