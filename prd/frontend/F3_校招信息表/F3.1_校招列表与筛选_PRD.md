# F3.1 校招列表与筛选

| 项目 | 说明 |
|------|------|
| **功能名称** | 校招信息表列表与筛选搜索 |
| **对应 FeatureList** | 3.1.1 列表展示、3.1.2 截止日期高亮、3.2.1～3.2.8 筛选与搜索 |
| **对应 ER 实体** | 校招岗位 |
| **对应时序图** | 时序图02_校招信息表浏览与解锁（若有） |

---

## 1. 需求背景与目标

- 用户在前台浏览已上架的校招岗位，通过多维度筛选与关键词搜索快速定位目标岗位；列表展示完整字段，截止日期临近或已截止有视觉区分。
- 目标：表格形式展示更新时间、企业名称、企业类型、招聘类型、工作城市、招聘岗位、所属行业、信息来源、网申时间、毕业生要求、投递链接（会员可见）、原文链接（会员可见）；支持招聘类型/企业类型/行业/城市/岗位类型/毕业生要求/网申时间范围筛选及全文模糊搜索；截止 ≤3 天高亮、已截止置灰。

---

## 2. 角色与入口

- **角色**：访客、注册用户（已登录但未开通校招会员）、校招会员。
- **入口**：顶部导航「校招信息表」；首页「校招信息表」入口。
- **数据范围**：仅展示已上架且未删除的校招岗位。

---

## 3. 页面结构与交互

- **整体布局**：顶部为「24h 校招求职会员信息动态」统计卡片 + 会员引导条；其下为筛选区（标签筛选 + 其他筛选 + 个人分组），再下为列表表格与分页。整体风格参考竞品：白底、浅灰背景、红色主按钮、标签色区分企业类型等。

### 3.1 统计信息与会员引导

- **统计标题区**：模块标题「24h 校招求职会员信息动态」，右侧展示最近一次刷新时间（例如「更新于：2026-02-25」）。
- **统计指标**（示例，实际数值由接口返回）：
  - 24h 内新增岗位数（如 32）；
  - 今日截止岗位数（根据 `apply_end_at` 判断）；
  - 7 日内更新岗位数；
  - 30 日内更新岗位数；
  - 日常实习岗位总数。
- **会员引导条**（位于统计卡片下方）：
  - 未登录或已登录但未开通校招会员时：展示提示文案（如「开通校招会员，可解锁投递链接/原文链接，并使用投递看板与简历库」）+ 红色按钮「开通校招会员」。
    - 未登录点击按钮：先弹出微信扫码登录弹窗（F1.1）；登录成功后跳转到会员开通页（套餐选择，F2.2/F7.1）。
    - 已登录未开通点击按钮：直接跳转会员开通页。
  - 已登录且为校招会员：可隐藏引导条，或展示弱提示文案（如「您已是校招会员，可直接使用投递链接与投递看板」），无强动作按钮。

### 3.2 搜索与筛选

- **搜索框**：位于筛选区上方，单行输入框，占位文案「搜索职位、公司，XXXX 家企业校招已更新」；输入后实时或防抖请求，企业名称/招聘岗位/城市模糊匹配。
- **标签筛选区**（第一行，类似竞品的标签条）：
  - 招聘类型：以标签形式展示，支持「全部」+ 若干常用标签（如 26届秋招/26届春招/日常实习/暑期实习），支持多选；值从接口 distinct 或字典获取。
  - 行业：标签形式，常用行业若干个，可点击切换；点击「更多」可打开下拉或弹出选择具体行业（见 M8.1 枚举）。
  - 城市：标签形式常用城市（全国、北上广深杭等），更多城市通过城市选择器选择。
- **其他筛选区**（第二行）：
  - 企业类型：多选下拉，国企/民企/合资/外企/事业单位/公益性。
  - 招聘岗位类型：多选下拉，产品/运营/技术/市场/职能/金融/其他。
  - 毕业生要求（Should）：毕业年份/学历要求，有数据则做。
  - 网申时间范围（Should）：截止日期起止。
  - 有公益推荐信息：开关（若有该数据）。
  - 按钮：「重置」「搜索」以及可选「完整模式」按钮（展开更多高级筛选项）。

### 3.3 我的筛选分组（仅登录用户）

- **入口与展示**：登录用户在筛选区下方看到「我的筛选分组」区域，包含若干分组标签（如「默认」「冲刺岗位」「保底岗位」）与「保存当前筛选」按钮。
- **保存分组**：用户设置好筛选条件后，点击「保存当前筛选」，弹出对话框填写分组名称，确认后保存为个人分组；同一用户可创建多个分组（建议数量上限，如 20 个）。
- **应用分组**：点击某个分组标签，前端按该分组记录的条件回填筛选控件并触发搜索。
- **管理分组**：支持重命名与删除；删除分组不会影响岗位数据，仅删除该筛选配置。
- **权限说明**：保存与使用「我的筛选分组」仅要求已登录，不要求是校招会员。

### 3.4 列表与分页

- **表格列**：更新时间、公司名称（含企业类型标签）、投递岗位、工作城市、网申时间、毕业生要求、浏览量（若有）、信息来源、投递链接、会员操作专区（见 F3.2）。非校招会员时，投递链接列显示「登录后可查看 🔒」或「开通会员解锁 🔒」，不直接展示真实链接。
- **截止高亮**（Should）：网申截止 ≤3 天红色高亮；已截止行置灰。
- **分页**：每页条数（如 20/50），总数与页码展示。
- **交互**：筛选变更后点「搜索」或自动请求列表；点击表头可选排序（默认按更新时间倒序）。

## 4. 字段规格表（列表与筛选）

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 更新时间 | updated_at | 列表 | datetime | 倒序 |
| 企业名称 | company_name | 列表/搜索 | string | 展示+模糊搜索 |
| 企业类型 | company_type | 列表/筛选 | enum | 国企/民企/合资/外企/事业单位/公益性，标签展示 |
| 招聘类型 | recruit_type | 列表/筛选 | string | 动态标签，多选筛选 |
| 工作城市 | city | 列表/筛选 | string | 多选筛选 |
| 招聘岗位 | job_title | 列表/搜索/筛选 | string | 多选筛选（产品/运营等） |
| 所属行业 | industry | 列表/筛选 | string | 多选，见 M8.1 字典 |
| 信息来源 | source_text | 列表 | string | 如腾讯官方公众号 |
| 网申开始/截止时间 | apply_start_at, apply_end_at | 列表/筛选 | date | 筛选为截止日期范围 |
| 毕业生要求 | graduate_requirement | 列表/筛选 | string | 文本展示；筛选 Should |
| 投递链接 | apply_url | 列表 | — | 会员可见，非会员🔒 |
| 原文链接 | original_url | 列表/会员操作区 | — | 会员可见 |

---

## 5. 业务逻辑与状态流转

- **R-01**：列表仅返回 publish_status=已上架、lifecycle≠已删除；投递链接与原文链接对非校招会员不返回真实 URL（防绕过）。
- **R-02**：筛选多选为 AND 关系；关键词搜索与筛选条件同时生效。
- **R-03**：招聘类型、行业等选项可从后台字典或表数据 distinct 获取，保证与后台维护一致。

---

## 6. 异常与边界

- 无数据：表格空状态「暂无岗位信息」。
- 搜索无结果：提示「未找到相关岗位，请调整筛选条件」。

---

## 7. 依赖与待定项

- **依赖**：校招列表接口（含筛选、分页）；字典/筛选项接口；权限控制由后端按会员类型控制返回字段。
- **待定**：浏览量是否展示及是否影响排序（V1 可不做）。
