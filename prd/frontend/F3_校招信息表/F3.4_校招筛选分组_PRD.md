# F3.4 校招筛选分组

| 项目 | 说明 |
|------|------|
| **功能名称** | 保存、切换、编辑与删除个人筛选分组 |
| **对应 FeatureList** | 3.2.x 筛选与搜索（保存分组） |
| **对应 ER 实体** | 用户、用户筛选分组 |
| **用户故事** | 作为已登录用户，我希望把当前筛选条件保存为命名分组（如「广州产品岗」），之后可一键切换分组并应用该组条件；并能编辑分组名称与条件、删除不需要的分组。 |

---

## 1. 验收标准（可闭环测试）

- [ ] **AC1** 「我的筛选分组」下拉与「保存当前筛选」**全员可见**（校招表首行）；未登录用户点击时弹出登录弹窗，登录后可使用；已登录用户直接使用。
- [ ] **AC2** 已登录用户可选择分组切换条件、点击「保存当前筛选」保存当前条件为命名分组。
- [ ] **AC3** 点击「保存当前筛选」→ 弹出**弹窗**；弹窗内展示**当前筛选条件摘要**（招聘类型、行业、城市、企业类型、网申截止、关键词等），并包含**分组名称**输入框（必填，如「广州产品岗」）；用户可修改名称后确认保存。
- [ ] **AC4** 保存成功后，该分组出现在「我的筛选分组」下拉中；选择该分组后，列表自动应用该组条件并刷新。
- [ ] **AC5** 支持**编辑**分组：在「我的筛选分组」或「管理分组」入口进入后，可选择某分组编辑名称或条件，保存后生效。
- [ ] **AC6** 支持**删除**分组：对某分组执行删除并二次确认后，该分组移除；若当前正在使用该分组，删除后恢复默认筛选或切换到其他分组。
- [ ] **AC7** 分组必须有**命名**；命名用于下拉展示与识别，不允许重名（或产品约定允许重名时的区分方式）。

---

## 2. 角色与入口

- **角色**：所有用户可见入口；**使用**（保存、切换、编辑、删除）仅已登录用户。
- **入口**：校招表页**首行**——「我的筛选分组」下拉 + 「保存当前筛选」+「管理」；未登录点击→弹登录。
- **数据范围**：分组按用户维度存储；仅当前用户可见自己的分组。

---

## 3. 页面与交互

### 3.1 保存当前筛选

- 触发：点击「保存当前筛选」。
- 弹窗内容：
  - **当前条件摘要**：只读或可微调（产品二选一），展示招聘类型、行业、城市、企业类型、网申截止范围、关键词等。
  - **分组名称**：必填输入框，占位「如：广州产品岗」。
  - 按钮：「取消」「保存」。
- 保存后：分组写入后端；弹窗关闭；「我的筛选分组」下拉中新增该项；可选自动切换到该分组并刷新列表。

### 3.2 我的筛选分组

- 展示：下拉选择框，选项为当前用户已保存的分组名称（按创建时间或自定义排序）。
- 行为：选择某分组 → 将该分组保存的条件应用到当前页筛选区（更新标签选中态、搜索框、日期范围等）→ 请求列表接口并刷新结果。
- 可选：展示「当前：广州产品岗」等，表示当前生效的分组。

### 3.3 编辑分组

- 入口：下拉旁「管理」或分组列表项上的「编辑」。
- 交互：进入弹窗或列表页，选择分组后可修改「分组名称」和/或「筛选条件」，保存后更新该分组；若当前正在使用该分组，应用新条件并刷新列表。

### 3.4 删除分组

- 入口：管理界面或分组项上的「删除」。
- 交互：二次确认（如「确定删除分组「广州产品岗」？」）→ 删除后从列表移除；若当前筛选正在使用该分组，则恢复默认筛选或提示用户选择其他分组。

---

## 4. 业务规则

- **R-01** 仅登录用户可使用保存、切换、编辑、删除；未登录不展示相关入口。
- **R-02** 分组与校招会员权益无关，登录即可用。
- **R-03** 分组数据按用户 ID 存储；切换分组时请求列表接口携带分组 ID 或分组对应的条件参数。
- **R-04** 分组命名唯一性：同一用户下不允许重名，或产品约定允许重名时的展示与选择方式。

---

## 5. 异常与边界

- 分组数量上限：若产品设上限（如 10 个），保存时超出则提示「分组数量已达上限，请删除后再保存」。
- 分组为空或条件无效：切换时按该分组条件请求，若后端返回空则列表为空状态。

---

## 6. 依赖与待定项

- **依赖**：登录态；筛选分组 CRUD 接口（创建、列表、更新、删除）；与 F3.3 筛选条件、F3.5 列表联动。
- **待定**：保存弹窗内是否允许在弹窗中直接修改条件再保存，由产品定；分组数量上限是否配置。
