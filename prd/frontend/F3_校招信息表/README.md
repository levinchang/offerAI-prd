## 与旧版 PRD 的对应关系

- 原 **F3.1 校招列表与筛选** → 拆分为：F3.1（概览与统计）+ F3.2（会员引导）+ F3.3（筛选与搜索）+ F3.4（筛选分组）+ F3.5（列表展示）。
- 原 **F3.2 校招权限与个性化** → 拆分为：F3.6（权限与行内操作）+ F3.7（收藏与已投递筛选）。

---

## 依赖关系

- **F3.1**：无前置故事，依赖统计/列表数据接口。
- **F3.2**：依赖 F1.1 登录弹窗、会员开通页（套餐选择）。
- **F3.3**：与 F3.4、F3.5 同页展示；依赖筛选项/字典接口、列表接口。
- **F3.4**：依赖登录态、筛选分组 CRUD 接口；与 F3.3 联动。
- **F3.5**：依赖校招列表接口（含筛选、分页）。
- **F3.6**：依赖 F1.1、会员开通页、投递记录接口（F6.2）、反馈接口。
- **F3.7**：依赖收藏接口、投递记录接口（F6.2）；与个人中心、F3.5 联动。
