# F3.3 校招筛选与搜索

| 项目 | 说明 |
|------|------|
| **功能名称** | 校招表多维度筛选与关键词搜索 |
| **对应 FeatureList** | 3.2.1～3.2.8 筛选与搜索 |
| **对应 ER 实体** | 校招岗位、字典 |
| **用户故事** | 作为求职者，我希望在首行就能看到求职进度、我的筛选分组、仅看收藏，并通过招聘类型、招聘范围、行业、城市等条件与关键词缩小目标岗位范围。 |

---

## 1. 验收标准（可闭环测试）

- [ ] **AC1** **首行（始终可见）**：**模糊搜索框**（占位「搜索职位、公司」）+ 求职进度下拉、我的筛选分组下拉、仅看收藏；搜索与三者**全员可见**，未登录/未开会员使用筛选时→弹登录或开通提醒。
- [ ] **AC2** **展开区（默认收起）**：招聘类型（默认「全部」）、**招聘范围**（26届、25届、27届等）、行业、城市、企业类型、网申截止、重置；标签多选，选中高亮。
- [ ] **AC3** 招聘类型、行业、城市支持「更多」弹窗/抽屉多选。
- [ ] **AC4** 网申截止：时间范围 + 快捷（今日截止、近三天、近七天）。
- [ ] **AC5** 模糊搜索：占位「搜索职位、公司」；校招表不包含学历要求筛项。
- [ ] **AC6** 「重置」：清空所有筛选与搜索，恢复默认并刷新列表。
- [ ] **AC7** 多选条件 AND；关键词与筛选条件同时生效。

---

## 2. 角色与入口

- **角色**：所有访问校招表页的用户；保存筛选分组仅登录用户可用（见 F3.4）。
- **入口**：校招表页，会员引导条下方。
- **数据范围**：筛选与搜索作用于已上架、未删除的校招岗位列表。

---

## 3. 页面与交互

### 3.1 首行筛选项（始终可见）

- **模糊搜索**：搜索框放在**首行**，占位「搜索职位、公司」，匹配公司名称、职位名称；全员可见。
- **求职进度**：下拉（全部、待投递、已投递、待笔试、已笔试、一面、二面、三面、已offer、未通过）。全员可见；未登录选择/点击→弹登录；未开会员选择/点击→弹开通提醒；登录且开会员后筛选生效。
- **我的筛选分组**：下拉选择已保存分组。全员可见；未登录点击→弹登录；未开会员可用（分组与会员无关）；登录后保存/切换正常。
- **仅看收藏（我的收藏）**：勾选后只展示已收藏岗位。全员可见；未登录勾选/点击→弹登录；未开会员勾选→弹开通提醒或仅展示空/占位；登录且开会员后生效。

### 3.2 展开区：标签式筛选

| 维度 | 说明 | 默认 | 多选 | 「更多」 |
|------|------|------|------|----------|
| 招聘类型 | 26届春招、秋招、日常实习、暑期实习等 | 全部 | 是 | 弹窗/抽屉多选 |
| **招聘范围** | **26届、25届、27届等，与列表「招聘范围」字段一致** | 不限/全部 | 是 | 可选 |
| 行业 | 金融、人工智能、新能源等 | — | 是 | 同上 |
| 工作城市 | 全国、北京、上海、广州等 | — | 是 | 同上 |
| 企业类型 | 国企、民企、合资、外企、事业单位、公益性 | — | 是 | 选项少可全展示 |

- 选中态：统一高亮样式（如红色字或红色边框/背景）。
- 「更多」交互：点击「更多」→ 打开弹窗或侧边抽屉，内为该维度全部选项（可带搜索），用户多选后点「确定」→ 关闭并更新筛选条件与列表。

### 3.3 网申截止时间

- 组件：日期范围选择器（开始日期、结束日期）。
- 快捷选项：**今日截止**（截止日=当天）、**近三天**、**近七天**（可选「已截止」）；点击后自动填充对应范围并刷新列表。
- 数据字段：apply_end_at（网申截止时间）。

### 3.4 模糊搜索

- 单搜索框，占位「搜索职位、公司」。
- 匹配字段：**公司名称、职位名称**（不支持城市/学历在此框内搜索；城市、企业类型已单独为标签筛选）。

### 3.5 重置

- 清空所有筛选条件与搜索关键词，列表恢复默认查询并刷新。

---

## 4. 字段与规则（筛选相关）

| 字段/维度 | 键名 | 类型 | 说明 |
|-----------|------|------|------|
| 招聘类型 | recruit_type | string 多选 | 默认全部，字典或 distinct |
| **招聘范围** | **graduate_scope / recruit_scope** | **string 多选** | **26届、25届、27届等，与列表字段一致** |
| 行业 | industry | string 多选 | 字典 |
| 工作城市 | city | string 多选 | 字典或 distinct |
| 企业类型 | company_type | enum 多选 | 国企/民企/合资/外企/事业单位/公益性 |
| 网申截止 | apply_end_at | date 范围 | 今日截止、近三天、近七天 |
| 关键词 | q / keyword | string | 匹配公司名称、职位名称 |
| 求职进度 | stage | enum | 与投递记录阶段一致，首行 |
| 仅看收藏 | favorited_only | boolean | 首行 |
| 筛选分组 | filter_group_id | — | 首行，登录后保存/切换 |

- **R-01** 多选维度均为 AND；关键词与各筛选条件 AND。
- **R-02** 校招表不提供「学历要求」筛选项。

---

## 5. 异常与边界

- 搜索无结果：列表为空并提示「未找到相关岗位，请调整筛选条件」。
- 筛选项加载失败：可降级为不展示该维度或展示默认项，不影响其他筛选。

---

## 6. 依赖与待定项

- **依赖**：校招列表接口（支持多参数筛选、分页）；筛选项/字典接口；与 F3.4 筛选分组、F3.5 列表联动。
- **待定**：「更多」优先用弹窗还是抽屉由 UI 定；完整模式中「毕业年份」等是否与后台 M3 字段完全一致，需与后端对齐。
