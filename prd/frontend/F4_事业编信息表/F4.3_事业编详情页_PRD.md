# F4.3 事业编详情页

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编/国企公告详情页（独立页面） |
| **对应 FeatureList** | 4.1.x 查看详情入口、4.3.x 原文与报名链接 |
| **对应 ER 实体** | 事业编岗位/公告 |
| **用户故事** | 作为求职者，我希望在列表点击「查看详情」后进入独立详情页，查看公告原文、报考条件、岗位明细等列表中无法完整展示的内容，并可跳转报名链接。 |

---

## 1. 需求背景与目标

- 列表仅展示关键字段，公告正文、报考说明、岗位明细等长内容需在**独立详情页**展示；从列表「查看详情」或点击公告标题进入。
- 目标：详情页信息完整、结构清晰，支持公告原文阅读、报名链接跳转（会员）、收藏与投递进度操作；登录态、会员态与校招表一致。

---

## 2. 角色与入口

- **角色**：访客、注册用户、事业编会员。
- **入口**：事业编列表页「查看详情」、列表公告标题点击；支持直接 URL 访问（如 /career/:id 或 #career-detail?id=xxx）。
- **数据范围**：单条公告详情；未上架/已删除返回 404 或无权限提示。

---

## 3. 页面结构与内容设计

### 3.1 整体布局

- **顶部**：返回列表（面包屑或「← 返回事业编列表」链接）。
- **标题区**：公告标题（H1）、类型标签、更新时间、报名时间范围、省/市/区域（或国家级）等摘要信息。
- **核心内容区**：分块展示，便于扫读；底部操作栏（报名链接、收藏、投递进度）。

### 3.2 内容区块建议

| 区块 | 内容 | 说明 |
|------|------|------|
| 基本信息 | 公告标题、类型、省份/市/区域、报名时间、招聘人数、学历要求、年龄要求 | 与列表字段一致，可重复展示便于单独页分享/收藏 |
| 报名链接 | 原文链接 / 报名入口 | 按钮或链接；非会员🔒 会员解锁，点击弹权益弹窗 |
| 公告原文 | 公告正文（富文本或纯文本） | 主体内容，可分段落、小标题；过长可折叠「展开更多」 |
| 报考条件/说明 | 学历、年龄、专业等要求及注意事项 | 若与「公告原文」分开存储则单独区块 |
| 岗位/职位明细 | 具体招聘岗位列表（岗位名、人数、专业等） | 表格或列表；若无则可不展示该区块 |
| 操作区 | 收藏、投递进度下拉、返回列表 | 与 F4.2 一致；登录/会员态控制 |

### 3.3 交互与权限

- **返回列表**：明确入口，返回时保留列表页筛选状态（若前端实现为 SPA 则保留；若新开页则列表为新状态）。
- **报名链接**：与列表一致，事业编会员可点击跳转；非会员显示「🔒 会员解锁」并弹权益弹窗。
- **收藏**：登录用户可收藏/取消收藏；未登录点击→弹登录。
- **投递进度**：事业编会员可选择阶段（已报名/笔试/面试/录用/未过），写入投递看板；未登录/未会员→登录或开通提醒。

### 3.4 视觉与适配

- 与全站风格一致（字体、主色、卡片圆角等）；正文区域最大宽度限制（如 720px）保证可读性。
- 移动端：区块纵向堆叠，报名链接与操作区固定或易达。

---

## 4. 字段规格表（详情页用）

| 字段显示名 | 字段键名 | 类型 | 说明 |
|------------|----------|------|------|
| 公告标题 | title | string | 主标题 |
| 类型 | job_type | enum | 标签展示 |
| 更新时间 | updated_at | datetime | — |
| 省份/市/区域 | province, city, district | string | 国家级时仅「国家级」 |
| 报名时间 | start_at, end_at | date | 范围展示 |
| 招聘人数 | recruit_count | number | — |
| 学历要求 | education_req | string | — |
| 年龄要求 | age_req | string | — |
| 报名/原文链接 | apply_url / original_url | url | 会员可见 |
| 公告原文/正文 | content / detail | text/html | 主内容区 |
| 报考条件说明 | condition_note | text | 可选 |
| 岗位明细 | positions | array | 岗位名、人数、专业等 |

---

## 5. 业务规则

- **R-01** 详情页数据与列表接口可分离（详情接口按 ID 返回完整字段）；非会员不返回真实报名/原文 URL。
- **R-02** 收藏、投递进度与 F4.2、F6 投递看板一致；来源=事业编表。

---

## 6. 异常与边界

- 无权限或已下架：提示「公告不存在或已下架」并提供返回列表入口。
- 正文过长：分块或「展开更多」避免首屏过长；图片/表格需适配小屏。

---

## 7. 依赖与待定项

- **依赖**：事业编详情接口、F4.1 列表入口、F4.2 权限与操作、F2.2 权益弹窗。
- **待定**：详情页为独立路由还是弹窗/抽屉由产品定；原型阶段采用独立页面（section 或 hash 路由）便于演示。
