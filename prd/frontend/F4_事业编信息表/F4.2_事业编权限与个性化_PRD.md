# F4.2 事业编权限与个性化

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编会员权限、个性化与投递联动 |
| **对应 FeatureList** | 4.3.1～4.3.2 原文链接锁定与解锁、4.4.1～4.4.2 收藏与分组、4.5.1～4.5.2 投递标记与隐藏已报名 |
| **对应 ER 实体** | 用户、收藏、分组、投递记录 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 非事业编会员不可见真实原文链接，点击弹权益弹窗；事业编会员可一键打开原文并可选写入投递记录。登录用户可收藏；会员可分组、标记报名阶段、隐藏已报名。
- 目标：与校招侧权限与个性化逻辑对齐，差异仅为「原文链接」对应事业编公告、「投递阶段」用事业编侧枚举（已报名/笔试/面试/录用/未过）。

---

## 2. 角色与入口

- **角色**：访客、注册用户、事业编会员。
- **入口**：事业编列表每行的「报名/原文链接」及行内操作区；事业编**详情页**（F4.3）同样提供报名链接、收藏、投递进度操作。

---

## 3. 页面结构与交互

### 3.1 报名/原文链接锁定与解锁

- **非事业编会员**：报名链接/原文链接显示「🔒 会员解锁」；点击 → 权益弹窗（F2.2），不返回真实 URL。
- **事业编会员**：报名链接可点击；点击 → 可选弹窗「是否记录到投递看板」→ 确认后新开标签打开原文/报名页，并可选写入投递记录（来源=事业编表，公告标题等自动带入）。列表与详情页（F4.3）行为一致。

### 3.2 收藏与分组

- **收藏**：同 F3.2，登录用户可收藏/取消收藏；未登录引导扫码。
- **加入分组**（Should）：与校招共用分组体系（F6.3），会员可将公告加入自定义分组。

### 3.3 投递标记与隐藏已报名

- **标记已报名/阶段**：会员在行内选择阶段（已报名/笔试/面试/录用/未过），写入投递看板；与 F6.2 投递记录一致，来源=事业编表。
- **隐藏已报名**：列表页开关「隐藏已报名」；开启后过滤掉已存在投递记录的公告。

### 3.4 会员操作专区

- 与校招类似：投递阶段下拉、编辑备注、查看公告原文、查看详情等；设计风格与 F3.2 一致，扁平化、红/蓝/灰按钮区分。

---

## 4. 字段规格表

与 F3.2 类似；阶段枚举为事业编侧：已报名、笔试、面试、录用、未过。

---

## 5. 业务逻辑与状态流转

- **R-01**：后端对非事业编会员不返回 original_url；投递记录来源字段区分校招表/事业编表。
- **R-02**：分组、收藏、投递记录与校招共用数据模型，仅来源类型不同。

---

## 6. 异常与边界

同 F3.2。

---

## 7. 依赖与待定项

- **依赖**：F2.2 权益弹窗、F6.2 投递记录、F6.3 分组、收藏接口。
- **待定**：无。
