# F4.1 事业编列表与筛选

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编/国企信息表列表与筛选搜索 |
| **对应 FeatureList** | 4.1.1～4.1.3 列表与截止高亮、4.2.1～4.2.4 筛选与搜索 |
| **对应 ER 实体** | 事业编岗位/公告 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户浏览已上架的事业编/国企公告，通过类型、省市区、学历、报名截止、关键词等筛选与搜索定位目标；列表展示关键字段，**查看详情**跳转独立详情页展示公告原文等完整内容；原文/报名链接对事业编会员开放。
- 目标：表格展示与校招表样式一致（首行筛选 + 展开区 + 表格）；支持模糊搜索（公告标题、招聘职位）、类型/省市区三级/学历/报名截止筛选；支持自有筛选分组、收藏、会员投递进度；列表含更新时间、公告标题、省/市/区域、类型、报名时间、招聘人数、学历与年龄要求、报名链接；详情跳转新页面。

---

## 2. 角色与入口

- **角色**：访客、注册用户、事业编会员。
- **入口**：顶部导航「事业编国企表」；首页入口。
- **数据范围**：仅展示已上架且未删除的公告。

---

## 3. 页面结构与交互（与校招表样式一致）

### 3.1 布局

- 与校招列表风格一致：会员引导条（未开通时 CTA，已开通弱提示或不显示）→ **首行筛选**（始终可见）→ **展开区**（默认收起）→ 列表表格 → 分页。

### 3.2 首行筛选项（始终可见）

- **模糊搜索**：占位「搜索公告标题、招聘职位」，匹配公告标题、招聘职位；全员可见。
- **求职进度**：下拉（全部、待投递、已报名、笔试、面试、录用、未过等，与 F4.2 事业编阶段枚举一致）。全员可见；未登录选择→弹登录；未开事业编会员→弹开通提醒；登录且开会员后筛选生效。
- **我的筛选分组**：下拉选择已保存分组；全员可见；未登录点击→弹登录；登录后保存/切换正常（与 F3.4 逻辑一致，事业编表使用事业编筛选条件）。
- **仅看收藏**：勾选后只展示已收藏公告。全员可见；未登录勾选→弹登录；未开会员勾选→弹开通提醒或占位；登录且开会员后生效。
- **重置**：清空所有筛选与搜索，恢复默认并刷新列表。
- **筛选**：按钮展开/收起下方「展开区」标签筛选项。

### 3.3 展开区：标签式筛选

| 维度 | 说明 | 默认 | 多选 | 备注 |
|------|------|------|------|------|
| 类型 | 事业单位/国企/银行/教师编/其他 | 全部 | 是 | 标签多选，选中高亮 |
| 省份/城市/区域 | **三级联动**：省 → 市 → 区；**国家级公告**无下级，仅「全国」或「国家级」单级 | 不限 | 是 | 国家级仅选「国家级」时无市/区；其他按省→市→区 |
| 学历要求 | 大专/本科/硕士/博士等 | — | 是 | 与列表「学历要求」一致 |
| 报名截止时间 | 日期范围 + 快捷（今日截止、近三天、近七天） | — | — | 同校招网申截止交互 |

- 选中态：统一高亮样式（与校招一致）。
- 省市区数据：省级列表；选省后加载该省下的市；选市后加载该市下的区；国家级公告在筛选中单独作为一级，选「国家级」时不展示市/区。

### 3.4 列表表格列

| 列名 | 字段/说明 | 展示说明 |
|------|-----------|----------|
| 更新时间 | updated_at | 日期或日期时间，倒序 |
| 公告标题 | title | 文本，可点击跳转详情页 |
| 省份/市/区域 | province, city, district | 展示为「省 / 市 / 区」或「国家级」；国家级时无市/区 |
| 类型 | job_type | 事业单位/国企/银行/教师编等，标签展示 |
| 报名时间 | start_at～end_at | 一般为范围，如「2026-02-01 至 2026-03-15」 |
| 招聘人数 | recruit_count | 数字 |
| 学历要求 | education_req | 大专/本科/硕士等，与筛选一致 |
| 年龄要求 | age_req | 文本，如「35周岁及以下」 |
| 报名链接 | apply_url / original_url | 跳转原文/报名页；事业编会员可见可点，非会员🔒 会员解锁 |
| 操作专区 | — | 查看详情（跳转详情页）、收藏、投递进度下拉等，见 F4.2 |

- **查看详情**：点击「查看详情」或公告标题 → 跳转到**事业编详情页**（新页面），展示公告原文及列表中无法完整展示的内容。
- 报名链接：会员可点击跳转原文/报名地址；非会员显示「🔒 会员解锁」，点击弹权益弹窗。

### 3.5 截止高亮（Should）

- 报名截止 ≤3 天红色高亮；已截止行或单元格置灰。与校招表一致。

### 3.6 分页

- 同校招：每页条数（如 20/50）、总数与页码；切换后保留筛选条件并刷新列表。

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 更新时间 | updated_at | 列表 | datetime | 倒序 |
| 公告标题 | title | 列表/搜索 | string | 模糊搜索，点击进详情 |
| 招聘职位 | job_titles / positions | 搜索 | string/array | 模糊搜索（职位名称） |
| 省份 | province | 列表/筛选 | string | 三级筛选第一级 |
| 城市 | city | 列表/筛选 | string | 三级筛选第二级；国家级无 |
| 区域 | district | 列表/筛选 | string | 三级筛选第三级 |
| 类型 | job_type | 列表/筛选 | enum | 事业单位/国企/银行/教师编/其他 |
| 报名开始/截止时间 | start_at, end_at | 列表/筛选 | date | 报名时间范围、截止高亮 |
| 招聘人数 | recruit_count | 列表 | number | — |
| 学历要求 | education_req | 列表/筛选 | string 多选 | 大专/本科/硕士/博士等 |
| 年龄要求 | age_req | 列表 | string | 列表展示，详情可展开 |
| 报名/原文链接 | apply_url / original_url | 列表 | url | 事业编会员可见 |
| 公告详情（原文等） | detail / content | 详情页 | text | 详情页展示，见 F4.3 |

---

## 5. 业务逻辑与状态流转

- **R-01**：仅返回已上架、未删除公告；非事业编会员不返回报名/原文真实 URL。
- **R-02**：筛选与搜索逻辑与校招一致，多选 AND、关键词模糊（公告标题 + 招聘职位）。
- **R-03**：省市区三级筛选：国家级公告单独一类无下级；其余按省→市→区联动。

---

## 6. 异常与边界

- 无数据：空状态「暂无公告」。
- 搜索/筛选无结果：提示「未找到相关公告，请调整筛选条件」。
- 详情页过长内容：在详情页内分块或折叠展示，见 F4.3。

---

## 7. 依赖与待定项

- **依赖**：事业编列表接口、筛选项（含省市区树）、详情页路由与详情接口；权限由后端控制报名/原文链接返回。
- **待定**：省市区数据来源与国家级标识方式需与后端约定；详情页路由命名（如 /career/:id 或 #career-detail?id=xxx）由前端定。
