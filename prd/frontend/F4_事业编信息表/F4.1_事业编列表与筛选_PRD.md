# F4.1 事业编列表与筛选

| 项目 | 说明 |
|------|------|
| **功能名称** | 事业编/国企信息表列表与筛选搜索 |
| **对应 FeatureList** | 4.1.1～4.1.3 列表与截止高亮、4.2.1～4.2.4 筛选与搜索 |
| **对应 ER 实体** | 事业编岗位/公告 |
| **对应时序图** | 无 |

---

## 1. 需求背景与目标

- 用户浏览已上架的事业编/国企公告，通过类型、省份、学历、关键词筛选与搜索定位目标；列表可展开查看详情，原文链接对事业编会员开放。
- 目标：表格或卡片列表展示更新时间、公告标题、省份、区域、类型、报名时间、招聘人数、职位数量；支持类型/省份/学历筛选及关键词搜索；截止 ≤3 天高亮、已截止置灰；点击展开或「查看详情」展示公告详情、学历/年龄要求、具体岗位列表。

---

## 2. 角色与入口

- **角色**：访客、注册用户、事业编会员。
- **入口**：顶部导航「事业编国企表」；首页入口。
- **数据范围**：仅展示已上架且未删除的公告。

---

## 3. 页面结构与交互

- **布局**：扁平化，与校招列表风格一致。搜索框 + 筛选区 + 列表（表格或卡片）；类型用标签区分（事业单位/国企/银行/教师编等），颜色可区分。
- **列表列/项**：更新时间、公告标题、省份、区域（市/区）、类型、报名开始/截止时间、招聘人数、职位数量、原文链接（会员可见，非会员🔒）、操作（查看详情、收藏、投递状态等，见 F4.2）。
- **查看详情**：行内「查看详情」或点击行展开；展开/详情页内容：公告详情（长文本）、报考学历要求、报考年龄要求、具体岗位列表。
- **截止高亮**（Should）：报名截止 ≤3 天红色高亮；已截止置灰。
- **筛选**：类型（事业单位/国企/银行/教师编/其他，多选）、省份（多选）、学历要求（大专/本科/硕士/博士，多选，Should）；关键词搜索：公告标题/岗位/省份/区域模糊匹配。
- **分页**：同校招，每页条数、总数与页码。

---

## 4. 字段规格表

| 字段显示名 | 字段键名 | 所在区域 | 类型 | 说明 |
|------------|----------|----------|------|------|
| 更新时间 | updated_at | 列表 | datetime | 倒序 |
| 公告标题 | title | 列表/搜索 | string | 模糊搜索 |
| 省份/区域 | province, region | 列表/筛选 | string | 省份多选筛选 |
| 类型 | job_type | 列表/筛选 | enum | 事业单位/国企/银行/教师编/其他，见 M8.2 |
| 报名开始/截止时间 | start_at, end_at | 列表/筛选 | date | 截止高亮规则 |
| 招聘人数/职位数量 | recruit_count, position_count | 列表 | number | — |
| 公告详情 | detail | 详情 | text | 长文本 |
| 报考学历/年龄要求 | education_req, age_req | 详情 | string | — |
| 具体岗位列表 | positions | 详情 | array | — |
| 原文链接 | original_url | 列表 | — | 事业编会员可见 |

---

## 5. 业务逻辑与状态流转

- **R-01**：仅返回已上架、未删除公告；非事业编会员不返回 original_url。
- **R-02**：筛选与搜索逻辑同校招，多选 AND、关键词模糊。

---

## 6. 异常与边界

- 无数据：空状态「暂无公告」。
- 详情过长：可折叠或分块展示，避免首屏过长。

---

## 7. 依赖与待定项

- **依赖**：事业编列表接口、筛选项、详情接口；权限由后端控制原文链接返回。
- **待定**：列表默认表格还是卡片由产品定，原型可先做表格与校招一致。
