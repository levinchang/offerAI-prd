# PRD 文档说明

## 与 FeatureList 的对应关系

- 每个 PRD 文档**必须在开头**注明：
  - **功能名称**、**对应 FeatureList 编号**（如 9.2.1、9.3.2）、**对应 ER 实体**、**对应时序图**（如有）。
- 开发时可根据 FeatureList 编号反查 PRD 文件路径（见 `backend/README.md` 索引表）。

## PRD 单文档结构（约定模板）

1. **Header**：功能名、FeatureList、ER、时序图
2. **需求背景与目标**
3. **角色与入口**
4. **页面结构与交互**
5. **字段规格表**（必填/长度/格式/取值来源/校验/错误提示）
6. **业务逻辑与状态流转**
7. **异常与边界**
8. **依赖与待定项**

## 目录约定

- 按**模块**建文件夹：`M1_登录`、`M2_飞书同步`、……
- 每个功能一个 Markdown 文件：`M2.1_飞书同步配置_PRD.md`。
- 文件名与文档内标题一致，便于检索。
